01 工具更新

GPT-5.6 Terra 与 Luna 加入 Agent Arena，测试时缩放在小模型上效果显著

GPT-5.6 Terra and Luna (xHigh variants) have joined Sol in Agent Arena! ... At Low, Terra dips flat and Luna falls -5.1% below baseline. ... More reasoning effort on a cheaper model can out-perform a pricier one running lean. Also notable: how steep Luna's curve is: test-time scaling is highly effective on smaller models.

实用点

对 agent 开发者来说，这是选择模型的重要参考：在 Agent Arena（基于真实长时 agent 任务）中，更便宜的模型（Luna）在高推理预算下能超越更贵的模型（Terra）运行在低推理预算，提示在 agent 应用中应优先考虑 test-time compute scaling 策略，而非盲目追求大模型。
