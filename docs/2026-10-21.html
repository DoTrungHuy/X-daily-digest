01 行业趋势

Cloudflare 联合 World Network 提出 Trusted Agent Delegation（TAD）框架

“introducing Trusted Agent Delegation (TAD) … the ultimate goal is for TAD to empower people to use their personal agents on any site across the internet, without sites getting crushed by fraud/abuse from bad bots or bad actors … it will also support next generation attestations and verifications, starting with World ID's Proof of Human”

实用点

做 agent 产品、尤其是“代用户操作第三方站点”的团队，需要关注这套“站点—用户—托管 agent”三方信任模型；白皮书与工作组将在数周内公布，可提前评估是否接入其证明/验证机制。

02 工具更新

Vercel 发布 durable-harness：Pi / OpenCode / Codex / Claude Code 等可持久化运行

“Introducing 𝚍𝚞𝚛𝚊𝚋𝚕𝚎-𝚑𝚊𝚛𝚗𝚎𝚜𝚜. Run Pi, OpenCode, Codex, Claude Code, eve, fx, or your own harness durably on Vercel. With 𝚍𝚞𝚛𝚊𝚋𝚕𝚎-𝚑𝚊𝚛𝚗𝚎𝚜𝚜, agents automatically resume work after failures and run for hours, days, or months.”

实用点

长时任务（批处理、监控、持续重构）不必自己搭断点续跑与失败恢复；可把现有 harness 直接托管，重点转向任务编排与成本控制。

03 工具更新

Codex & Work 第 16 天：API 缓存 12 小时，登录用户跨会话缓存永久保留

“You can now cache for 12h in the API and for logged in users across Codex & Work we keep cache forever and you don't have any penalty for coming back to an old conversation or resuming after a few hours and are now guaranteed to hit the cache.”

实用点

这是此前“子 agent 复用上下文、延长缓存”的后续版本，新增点是 API 侧 12 小时上限与登录用户“永久缓存 + 保证命中”。对频繁恢复旧会话的 agent 工作流，可显著降本降延迟；API 集成方需按 12 小时窗口设计会话复用。
