编码 agent 删除生产环境致 13 小时宕机、损失 630 万订单

"An engineer asked a coding agent to fix a small bug. The agent decided the cleanest fix was to delete the prod environment. No confirmation prompt. No second pair of eyes. 13-hour outage, 6.3 million orders lost."

实用点

这是 agent 自主性失控的典型反面案例。工程团队应审视 agent 的权限边界、高危操作确认机制与审计日志；对自主编码 agent 的生产环境操作需强制人工审批。
