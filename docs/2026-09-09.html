02 工具更新

ChatGPT Images 2.5 发布：全端上线 + 两款新 API 模型

"ChatGPT Images 2.5 is rolling out today to all ChatGPT, ChatGPT Work, and Codex users across desktop, mobile, and web. We're also introducing two new models in the API: GPT-Image-2.5 Flare brings the same quality, editing, and speed improvements, while GPT-Image-2.5 Sunburst adds precision for detailed creative work, with longer generation times."

实用点

图像生成进入 2.5 时代。API 侧新增 Flare（快速）与 Sunburst（精细）两个档位，适合不同生成场景。新增 comment-based edits 可只改局部细节，对需要多轮迭代的 UI mockup 或素材生成工作流有实际价值。

03 行业趋势

Meta Muse Spark 1.3 Max 重塑 Code Arena: WebDev Pareto 前沿

"Muse Spark 1.3 Max performs just 20 pts lower than Qwen3.8 (Max) while costing 30% less, and 24 pts from Kimi K3 (Max) while costing 70% less. Muse Spark 1.3 Max: 1650 pts | $3.50/M"

实用点

Meta 新模型在 WebDev 基准上以 $3.50/M 的价格拿下 1650 分，填补了 $0.39-$5/MToken 之间的性价比空档。对价格敏感的前端生成任务，这是目前最值得测试的选项之一。Code Arena 前沿图持续被刷新，选型时建议以最新数据为准。

04 大佬官方

sama 公开称赞 Ant Claude Code 后台计算机使用能力，并呼吁行业跟进

"I am pleased to see that Ant's new Claude Code has a version of background computer use on par with the version from Codex from last May this year. Nice work! ... We solved computer use in practice for GPT models about four months ago. But computer use is a significantly awesome thing no matter what model you use, and it is important that the industry similarly spends more effort to train their models to be great at computer use."

实用点

OpenAI CEO 罕见正面评价竞争对手。背景计算机使用（background computer use）正成为 agent 能力竞争的关键维度。若你在构建需要长时间自主操作的 agent，建议同时对比 Codex 与 Claude Code 的实现方式。

05 行业趋势

测试时计算成本骤降：从 o3 的 $500K 到 Astra 的 ~$20

"when @OpenAI announced o3 it cost ~$500,000 to score 87.5% on ARC-AGI 1. Today, Astra scores higher for ~$20. In 2025 it took us and GDM an enormous amount of compute to achieve IMO gold. For the 2026 IMO, anyone with a $20/month ChatGPT subscription could do it."

实用点

测试时计算（test-time compute）的成本曲线正在以数量级速度下降。对开发者而言，这意味着原本只有大厂才能负担的高难度推理任务，正在进入个人开发者可及范围。规划产品时可将"高难度推理"类功能纳入路线图。

kirodotdev 向 18 国 132 所大学学生提供免费一年 spec-driven coding agent

08 工具更新

tparse：将杂乱的 Go 测试输出转为清晰摘要

"tparse turns messy Go test results into a clear summary of what failed, passed, or panicked. Highlights failures and panics automatically, Shows passed tests with timing details, Works from saved output files too."

实用点

Go 测试的原始输出可读性差是长期痛点。tparse 自动高亮失败与 panic、显示通过用例耗时、支持从已保存的输出文件解析。适合 CI 日志排查与本地测试结果快速浏览，值得加入 Go 工具链。

09 工具更新

Experiential：统一多模型调用的 agentic AI 网关

"Experiential is an agentic AI gateway. Use hosted, BYOK, and local models through one OpenAI-compatible API, then turn real AI traces into simulations for automated evals and training. For a limited time, Experiential is also offering 1000+ models free through its hosted catalog."

实用点

多模型切换与 trace 回放是 agent 开发的两大痛点。Experiential 通过单一 OpenAI 兼容 API 聚合 hosted/BYOK/本地模型，并可将真实 trace 转为模拟数据用于自动化评测。限时提供 1000+ 模型免费使用，适合做模型对比评测的团队尝试。
