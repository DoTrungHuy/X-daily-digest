01 大佬官方

OpenAI 与 FMF 成员机构发布“网络越狱严重性”评估框架

“We partnered with @fmf_org and its member firms on a new framework to help identify when bypassing an AI system's safeguards could enable serious cyber harm, and prioritize stronger protections.” — OpenAI 国家安全政策负责人 Sasha Baker 称这是走向“评估与比较网络越狱严重性”的共同方法论的一步。

实用点

做安全评测/红队的团队可关注其“能力解锁程度 + 可复用难易度”两个维度，作为自建 jailbreak 分级表的参照；与近期 Daybreak 双线、漏洞赏金扩档属同一安全叙事线，但这是新发布的方法论，不是旧闻重复。

02 大佬官方

BioBasicsBench：用 100 个真实实验任务测 agent 做“湿实验室日常分析”

“A new way to measure how AI agents handle the routine analyses of wet-lab science—BioBasicsBench.” 与酶设计公司 Ligo 合作，任务取自真实实验，考察 agent 能否解读原始实验数据、发现错误、并识别“证据不支持结论”的情形。

实用点

这是少见的“agent 该不该说不知道”型基准，对做工具调用 agent 的开发者有直接借鉴：把“拒绝下结论”作为可评分行为，而非失败。也提示生物类 agent 的评测重点在数据清洗与误差识别，不在生成。

03 大佬官方

Anthropic 工程博客：用“dreaming”机制帮 Claude 整理记忆、纠错、提升召回

“Memory is what allows Claude to learn from experience. In a new Engineering Blog post, we share how ‘dreaming’ helps Claude organize what it’s learned, correct its mistakes, and find what it needs more easily the next time.”

实用点

对做长期记忆/上下文管理的 agent 工程有参考价值——把“离线整理记忆”当作独立阶段（类似睡眠期巩固），而不是在推理时硬塞检索。具体实现细节需读原文，本条仅为发布信号。

04 大佬官方

Anthropic 科学博客：AI 开始参与“写模型”本身——写、跑、拟合、修订科学模型代码

客座作者 Jakob Macke 等指出，过去 AI 主要帮科学家把复杂模型拟合到数据，但“scientists still typically write the models manually”，且要在多个竞争解释间权衡；AI 现在可以“writing, running, fitting, and revising scientific models as code”，探索多种模型结构并找出数据支持哪一种。

实用点

这是“agent 做科学”从拟合走向模型搜索/模型选择的方向性描述，对做自动化实验循环（propose–run–fit–revise）的团队是可复用的抽象；注意这是观点文，非基准结果。

05 工具更新

Notion：agent 的工作过程可直接在评论里跟进

“Follow along as your agents work, right in the comments.”

实用点

把 agent 执行轨迹落到协作界面（评论流）而非单独日志面板，是 agent 可观测性的一种产品化做法；对自建 agent 的团队，可考虑把中间步骤写回用户已在看的地方，降低“黑箱感”。此为 Notion agent 能力的新增交互，非此前 MCP/setup prompt 话题的重复。

06 工具更新

Notion 补齐与 ChatGPT 的双向接入，并称将扩展到其他模型供应商

“You can now: - Use Notion and leverage all OpenAI models - Use ChatGPT and leverage Notion via MCP - Use Notion w/ your ChatGPT subscriptions - (and today) Use ChatGPT with Notion plugin. And yes, we're working on … enabling this with other providers too.”

实用点

新增点是“ChatGPT 侧 Notion 插件”这一条，加上可用 ChatGPT 订阅额度在 Notion 内调用模型；对已在 Notion 里搭 agent 工作流的团队，意味着入口从 MCP 单向变为双向。与既有“仅开 MCP 不够、需 setup prompt”的讨论互补而非重复。
