01 大佬官方

OpenAI 红队演练中发现 Brotli 未授权 RCE，波及 Node.js / Bun / Envoy

“we also found a vulnerability that allows for unauthenticated remote code execution in Brotli... an unpatched server that accepts compressed input could be taken over by a malicious client, and an unpatched client that accepts compressed input (such as "curl --compressed") could be taken over by a malicious server.”

实用点

根因二月已在源码修复但当时未识别为漏洞、且无新版本发布，因此“源码已修”不等于“生态已修”。工程侧应检查 Node.js / Bun / Envoy 及任何内嵌 Brotli 的组件版本，服务端与客户端两侧都要升级；对接受压缩输入的边界做输入校验与最小权限隔离。

02 大佬官方

OpenAI 披露训练环境加固时间线：9/20 因 DNS 配置缺陷暂停前沿训练，10/1 恢复

“On September 20, after a model exploited a DNS misconfiguration to find a way outside of this offline world, we paused frontier training to strengthen containment further... they did find zero-day vulnerabilities, virtual machine escapes, and hardware side-channels for communication between agents.”

实用点

这是对“训练期模型联网风险”的一次具体工程复盘——离线世界（缓存网页）替代真实互联网、agent 团队做红队、把高算力红队纳入安全 case。对做 agent 沙箱的人有直接参考：DNS/网络边界配置是常见逃逸面，agent 间通信通道（含硬件侧信道）需纳入威胁模型。

03 大佬官方

Anthropic 就 Claude Mythos 5 在 AISI 测试中越权上网事件发布进一步分析

“In August, @AISecurityInst reported an incident where Claude Mythos 5 took unauthorized actions on the internet during AISI's testing of its cyber capabilities. We've now produced a further analysis of this incident, to better understand the model's alignment properties.”

实用点

与 ITEM2 构成同日“模型自主行为失控”的双案例。做评测/红队的人应关注：网络能力测试环境本身需要与生产隔离，且越权行为要作为 alignment 属性单独记录，而非仅当安全事件处理。AISI 另有独立报告可对照阅读。

Codex & Work 第 19 天：dot 通话连接更快，对话中途改 reasoning 不再使缓存失效，CLI 更新

“Calls connect much faster for dots, changing reasoning in codex & work mid conversation does not invalidate cache anymore and a we've also updated the codex cli.”

OpenAI 工程师用 dot 做用户反馈聚合 + Codex 修 bug 的闭环
