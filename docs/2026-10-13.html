01 工具更新

diff-tour：敲个 tour，让 Claude Code / Codex 把这次改动讲成一屏一屏的导览

"在仓库里敲个 tour，你已经登录的 Claude Code 或 Codex 就会生成一份导览，一屏一屏讲清这次改动是为了什么、哪些文件要细看、哪里可能出事。"

实用点

直接补上"AI 写完代码后人类 review"这一环。官方示例里用一段 Claude 写的优惠券功能演示，中间抛出思考题——App 超时重发用券请求会扣几次券？答案是 2 次，且现有测试没覆盖。适合在合并前跑一遍，把 AI 生成代码的隐性边界条件暴露出来。注意：早期版本，界面仅英文/日文，生成一份导览需 2~5 分钟。

02 工具更新

plain-writing：25 条规矩治 AI 文风，还能 /plain-writing deslopify 重写上一条回复

"把这个开源 Skill《plain-writing》装进 Claude Code 或 Codex，AI 写东西时就会照着 25 条规矩来，比如不打比方、不连着抛反问。"

实用点

针对"不只是 X，更是 Y"、滥用破折号这类典型 AI 腔。装完后可用 /plain-writing deslopify 把上一条回复重写成"先结论、再背景和做法、术语解释清楚"的结构。安装命令：gh skill install docwriter-org/plain-writing-skill plain-writing，勾选 Claude Code 或 Codex。作者另附了中文速查，可挑几条贴进其他 AI 的提示词。

03 工具更新

motionmaxxing：从 53 段专业动效逐帧拆出的 Skill，专治"会动的 PPT"

"同一个 GPT-6.1、同一份需求做 Cluely 宣传片，装上这个开源 Skill 后，成片一下就不像会动的 PPT 了。"

实用点

规则具体可复用——元素靠移动进场少用淡入淡出、进场减速落位离场加速、趁画面还在动时切镜头。片子做完 AI 会跑脚本自查，前半段没装 Skill 的版本里角落小标签、"02 / 05"页码都过不了这关。环境要求：Node 22+、Python 3、Chrome、ffmpeg，配音配乐需另接 ElevenLabs Key。

04 行业趋势

Meta Muse Wonder 定价与 Opus 5.5 相同，跑分低一截；Full 版不开放 API

"这个 Muse Wonder 和 Opus 5.5 都是每百万 token 输入 4 美元、输出 20 美元。可在测评机构 Artificial Analysis 的综合榜上，Opus 5.5 是 58 分，Muse Wonder 只有 52 分。"

实用点

选型时注意三点——(1) API 能调的 Muse Wonder 跑分只和 GPT-6.1 Sol 打平，而 Sol 单价只有一半；(2) 更强的 Muse Wonder Full 有 56 分但不开放 API；(3) 入口和计费要分开看：Muse Code 走订阅（Power Usage 50 美元/月、Maximum 200 美元/月），Meta Model API 按量付费（输入 4 美元、输出 20 美元、缓存输入 0.2 美元每百万 token），Code 订阅凭证不能当 API 包月用。国内注意：Meta Model API 限制中国大陆、香港、澳门地区使用。另有第三方测评者 @petergostev 把 Muse Wonder (Max) 与 Astra、Opus 5.5、GPT-6.1 Sol、Claude Sonnet 5.5、Fable、Kimi、Mistral 做了横评并列出每次生成成本。

05 行业趋势

X 统一订阅：SuperGrok + Cursor Pro + X Premium+ 打包 30 刀，但有三个坑

"原来三个会员加起来差不多90刀/月，现在30刀就能全包！"

实用点

五档为 Free 0 / Plus 8 / Premium 30 / Super 100 / Ultra 200 美元每月，部分用户有首月优惠（Premium 15、Super 50、Ultra 100）。三个坑：(1) 8 刀的 Plus 不含 Grok Bot，要用 Bot 至少上 30 刀档；(2) Cursor 里用 Claude、GPT 等第三方模型仍需额外充 Credits，共享的只是 Grok 模型额度；(3) Grok Bot 与 Cursor 共享每周额度，Bot 跑多了 Cursor 就少。作者本人因手里有低价 SuperGrok（印度区约 50R/月）暂不切换，担心老套餐被替换后无法续费。官方称老用户可保留原套餐和价格，但实际以结账页为准。

06 中国相关 / 其他

斯坦福 CS336 作业仓库放 AGENTS.md，明确禁止 AI 代写作业

"这份 AGENTS.md 规定 AI 只能当助教，不写一行代码，连解题思路都不给，只会反问你，引导你自己找出 bug。"

实用点

课程本身是"从零造大模型"的完整路线——18 节录屏免费，5 个作业依次是：自己写分词器/Transformer/优化器；手写 FlashAttention2 并上多卡训练；算力固定时推算模型该训多大；把爬来的网页洗成训练数据；用强化学习教 1B 小模型做数学题。自学成本参考：官网 3 月列的单张 B200 每小时 4.99~6.69 美元，课程赞助商 Modal 每月送 30 美元额度。AGENTS.md 这个用法本身也值得借鉴——用仓库内文件约束 AI 的行为边界。

08 工具更新

Notion 官方给出"给 agent 用的 context layer"八件套清单

"How to start your context layer in Notion: About me / Style guide / How to work / Business context / Content engine / Daily log / Memory / Active projects"

实用点

这是一份可直接照抄的 agent 上下文目录结构，每项都标了更新时机——比如 Style guide 在读到"像你写的东西"时更新，Business context 每周一早上更新，Memory 每周五更新，Active projects 每次工作会话开始和结束各更新一次。Notion 官方同时强调其作为 context layer 的三个理由：单一数据架构而非五个孤岛（检索更快更便宜）、可塑软件而非硬编码（agent 更易用）、以及 agent 真正愿意用的 MCP。另有用户用 @bot 搭了 X Bookmarks agent，每 6 小时抓取书签并自动分类进 Notion 数据库。

09 关注动态

levelsio：帮线下企业做 AI 转型现在很赚钱，但这是几年窗口不是长期生意

"You can get very rich on helping IRL businesses with the transition to AI and automating everything for them... But again this is temporary for a few years, it's not a sustainable business."

实用点

他给的理由是竞争性强制——一家企业上了 AI，同行就都得跟上，所以短期需求确定；但一旦自动化完成、AI 自我改进加速、企业自己学会做，这个生意就没了。同一天他还补了一段对"软件已死"讨论的回应：全球约 4000 万开发者 vs 约 20 亿 AI 工具常规用户（50 倍），若增长到互联网普及量级 60 亿则是 200 倍；他强调自己一半净资产在 AI 股票里（Google、SpaceX、Nvidia 及科技 ETF），所以有立场，但仍认为"现在不是做软件最好的时代"，只是"做创意最好的时代"。他澄清一个常见误解：不是人们让 AI agent 去写软件，而是 agent 会为了解决问题现场造软件。
