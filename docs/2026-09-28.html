01 工具更新

Distributed Llama：用家用以太网把多台机器连起来跑大模型，四台 Mac Mini 可跑 70B

"Distributed Llama links your home computers over Ethernet to run large AI models faster, even letting four Mac Minis handle a 70B model."

实用点

对没有 GPU 集群的个人开发者，这是把闲置机器变成推理池的低成本路径；关注点应在以太网带宽与层间通信开销，而非单机算力。适合做本地推理实验、隐私敏感场景的自托管。

02 工具更新

单个 Rust 程序跑自改进 agent：跨聊天渠道、生成图像与文档、本地或托管模型均可

"Run a self-improving AI agent from one Rust program. - Works across many chat channels - Generates images and documents - Runs local or hosted AI models"

实用点

单二进制、多渠道路由、模型可切换，是 agent 运行时的一种极简架构取向。对想自建 agent 但不想引入 Python 依赖树与消息队列的工程团队有参考价值；"self-improving" 的具体机制原文未说明，需自行核实。

03 行业趋势

GreyNoise 记录的 agent 驱动 PaperCut 攻击：经长期存在的服务账号从 280 家组织取走 AD 凭据

"The agent-run PaperCut campaign GreyNoise documented took Active Directory credentials from 280 organizations through standing service accounts. Leaver checklists still only have rows for people."

实用点

这是"非人类身份"治理的具体案例——离职清单只管人，不管服务账号。对做企业 agent 部署的团队：把服务账号纳入轮换与下线流程，比在模型层加防护更直接。

05 行业趋势

Apollo 首席经济学家：agent 可能引发银行挤兑——把家庭现金扫进 3-5% 的账户

"Chief Economist at Apollo: agents could cause a bank run by sweeping household cash into accounts paying 3-5% instead of the 0.1% national average, causing banks to lose a large share of their cheap deposits."

实用点

这是 agent 在金融场景下的二阶效应推演，非既成事实。对做 agent 金融自动化的开发者：批量、低摩擦的资金调度本身就是系统性风险面，限额与速率控制应在设计阶段考虑。
