01 大佬官方

Anthropic 把 Messages API 从 Python 迁到 Rust，用 Claude agent 团队做新旧版本差分验证

“We recently migrated our Messages API from Python to Rust. On our engineering blog, we share how we used the existing service to verify the new one, with teams of Claude agents tracking down and fixing differences between the two versions.”

实用点

这是“重写 + 等价性验证”的工程范式：以旧服务为 oracle，让 agent 团队逐差异定位并修复，比一次性大重写更可控。做语言迁移或性能重写的团队可直接借鉴这套差分流程。

02 行业趋势

sama 称矩阵乘法指数上界 9/4 已被证明是紧的，并推出 LP 可在 n^{9/4} 求解

“we had a particularly clean advance on the matrix multiplication exponent, with a new upper bound of 9/4. Since then, the model has been working on a LOWER BOUND... Today we announced that actually 9/4 is tight... by an 'old' result of Yin Tat Lee and collaborators this also implies that linear programs can be solved in time n^{9/4}.”

实用点

若成立，这是理论 CS 的罕见双向闭合结果（上界与下界相遇），并直接波及线性规划复杂度。注意这是转述，具体证明需看原始论文再引用。

OpenAI 承认 GPT-6.2 上线计费错误，修正后 Astra/Sol 额度消耗分别快 40%/25%，补偿一次 banked reset

“We made a billing mistake at launch of GPT-6.2 that incorrectly discounted GPT-6.2 Astra and Sol usage for most users. 05 工具更新

gitai：开源 Git 托管，多个编码 agent 用 compare-and-swap 落到同一分支而不排队

“gitai is open-source Git hosting where many coding agents land on one branch without queue stalls, via compare-and-swap.”

07 行业趋势

1Password 因单个被劫持的 GitHub 账号被入侵，六天后才告知客户

“1Password, the company you pay so nobody steals your passwords, got breached through one hijacked GitHub account and told customers six days later. Your vault was fine, they say. Their own front door wasn't.”

实用点

供应链攻击面再次落在“开发者身份”而非产品本身。团队应检查 GitHub 组织成员的 2FA/硬件密钥、CI 与发布流程的权限边界，以及第三方账号的告警延迟。
