01 工具更新

levelsio 用 Claude Code + 本地模型全自动剪出 10 分钟 vlog

“My vlog today was fully edited by Claude Code with Opus 5.5! … All I asked for was 'Claude can you edit these clips into a 10 minute vlog for X and YouTube'”

实用点

这是一条可直接复刻的 agent 流水线：mlx-whisper（Whisper large-v3-turbo，走 Apple MLX/GPU）做转写 → 每隔几秒抽帧拼 contact sheet 让模型“看”画面 → SpeechBrain ECAPA 做声纹区分本人与他人 → OpenCV YuNet 做人脸缩略图 → 剪辑决策落成 JSON 的 cut 列表（clip/start/end）→ Pillow 加字幕。对做多模态 agent 的人，关键设计是“把视频离散成文本+图像网格，让模型输出结构化编辑指令而非直接操作时间线”。另据其回复，58 分钟 14 段素材剪到约 10 分钟。

02 工具更新

AnyShot 开源：把 Blender 场景分发到最多 100 张 RTX 5090 渲染，并带 AI 摄影指导

“on my RTX 5070 Ti, a single walkthrough like this takes 6 hours to render. AnyShot fans it out across up to 100 RTX 5090s on @fal and renders it in 3 minutes.”

实用点

不只是渲染农场——输入任意 Blender 场景加一句 brief，AI 摄影指导会规划每个机位运动、检查不穿模、做跟焦。开源。对做 3D/视频生成 pipeline 的人，这是“任务编排 + 结构化场景描述 + 云端弹性算力”的一个完整参考实现；本地 6 小时 vs 云端 3 分钟的量级差也说明了 fan-out 调度的价值。

03 行业趋势

Grok Bot 模板被指“功能即分发机制”

“grok bot templates are a VERY good example of a feature that doubles as a distribution mechanism... look closely and they're basically instructions, simple prompts for each agent”

实用点

观察点是产品设计层面——模板本质是 prompt，但因为易复制分享，用户在 X 上自发建市场、刷互动甚至售卖，形成低成本分发。对做 agent 产品的团队：把“可分享的配置单元”设计成一等公民，比做封闭功能更容易获得传播。属观点而非事实，需自行判断。

04 工具更新

Grok Bot 团队实时看板：3D 办公室视图 + 用量归因

“1 prompt + 2 min + <1% usage = ... every team on its own floor of live 3D office / see exactly which bot is eating your usage”

实用点

实现思路值得借鉴——用一个“manager” bot 通过 ntfy（免费实时消息通道）建立私有频道，并向所有 bot 的共享记忆写入一条规则：启动/完成/卡住/需要人时各发一行。于是看板只是读这个频道。这是用“共享记忆 + 单向事件日志”做多 agent 可观测性的轻量方案，不依赖专门的后端。作者称在其 Super Plan 上占用 <1% 用量，未独立验证。

TeamViewer 高危漏洞：被连接的“主机”可反向攻击你

“TeamViewer had a bug where the machine you connect to can attack you back. You connect to help. The host lies about its screen size, your app crashes, and on Windows researchers ran their own code”

实用点

修复版本 15.83，尽快打补丁。对做远程协助/远程桌面类工具或 agent 远程操作能力的人，这是一个典型威胁模型提醒：客户端默认信任对端上报的元数据（如屏幕尺寸）是危险的，任何“被控端→控制端”的数据都应视为不可信输入。
