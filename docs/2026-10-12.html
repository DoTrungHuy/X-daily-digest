01 工具更新

Codex 里 GPT-6.1 Sol 默认上下文 272k → 500k，且长上下文不再多扣额度

"Codex 里 GPT-6.1 Sol 默认上下文从 272k 涨到 500k……官方紧跟着补了一句：用会员跑 Sol，长上下文不再多扣额度了！"

实用点

默认值变化本身不算新功能，但"长上下文不再额外扣额度"是实打实的成本变化——以前手动调到 272k 以上要多扣，现在默认 500k 且自动压缩更少。想试 1M 可在 ~/.codex/config.toml 顶部加 model_context_window = 1000000 与 model_auto_compact_token_limit = 900000，重启后新开会话生效。注意这与两天前 Tibo 说"开到 1M 也行，就是更费额度"的口径相反，说明额度策略仍在调整中。

Tibo 的 5h 限额投票结果：9.1 万票反对，官方尚未定案

"不要 5h 限额、额度不变：91040 票；加回 5h 限额、周额度翻倍：79775 票……Tibo 自己发帖说这结果让他很困惑"

实用点

约 53% 对 47%。作者的分析是"翻倍是看不见的，5 小时墙是实打实的"——大任务跑到一半被卡死、拼车用户尤其受影响。对重度用户而言，可预期性比名义额度更重要。官方未公布最终方案，别把投票当结论。

03 行业趋势

哈佛新开 AI Agent 课，课件与作业边上课边公开

"1️⃣ 用 Claude Code 给 Claude Code 自己做个网页界面 2️⃣ 自己写个 Agent 3️⃣ 任务成功率不变，把成本和延迟压下去 4️⃣ 拿掉商业 API，自己部署 7~8B 的开源小模型，还不许换更大的 5️⃣ Agent、模型和跑模型的推理引擎一起调优"

实用点

作业 3、4、5 是很好的自测题——固定成功率压成本/延迟、被迫用 7~8B 小模型、联合调优推理引擎，都是真实生产约束。第 8 讲提到同一对话每多聊一轮模型都要重读前文，总成本按轮数平方涨，值得对照自己的 agent 循环做优化。目前只有课件无录像，下半段 10 月 19 日开讲。

04 工具更新

ManimGX：开源 3D 数学动画引擎，提示词交给 Claude Code / Codex 即可渲染

"把一句提示词丢给 Claude Code 或 Codex，AI 就会照着文档自己安装、写代码，渲染出 3D 动画……作者自测渲染速度是老牌动画库 Manim 社区版的 90 倍，不装 LaTeX，中文标题和公式也能正常显示"

实用点

适合做教学/科普视频的开发者。作者给出的可复制提示词是"照着文档装好 ManimGX，做一个太阳系的 3D 动画，做完打开"。渲染速度 90 倍为作者自测口径，未独立验证；不依赖 LaTeX 对中文用户是实际便利。

05 工具更新

lintapple：给 AI 写的界面做"质检"的 npm 包

"它会在浏览器里打开页面，挨个元素对着规矩量一遍……字号只能用你定好的那几档；普通文字和背景的对比度至少 4.5:1；按钮之间至少留 8px……报告里会写明哪里不合格、量出来是多少、该怎么改"

实用点

把"AI 味界面"变成可量化的 lint 规则，报告可直接喂回给 AI 逐条修。实测案例：AI 写的后台页面筛选按钮浅灰数字对比度只有 2.56:1。安装 npm install -D lintapple && npx lintapple init，需 Node 22+；对齐、圆角两项需先给元素加规定标记。

06 行业趋势

Karpathy 的 AI 认知漏斗：约 2000 万人见过 Agent 干完大项目

"约 60 亿人几乎没碰过 AI，10~20 亿人偶尔用免费版……再往下只剩约 2000 万人，见过 Agent 一句提示词做完几周、几个月的大项目"

实用点

Karpathy 归因于三点——一段话能答完的问题考不出 AI 水平；代码有单元测试可判对错，AI 在这类任务上最强；免费版与付费版差距。对做 agent 的人，这解释了为什么"可验证的任务"是当前 AI 收益最高的场景。

levelsio：该退休"vibe coding"这个词了，现在叫 precision engineering

"it's clear we need to retire the term vibe coding because the models now produce better architecture & way more coherent code than an average software engineer……this ain't vibe coding at all. it's precision engineering."
