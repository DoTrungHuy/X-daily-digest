01 行业趋势

BragJack 恶意浏览器扩展劫持 Chrome / Edge / Opera Neon / Comet / Claude-in-Chrome 中的 AI agent

"One malicious browser extension just hijacked AI agents across Chrome, Edge, Opera Neon, Comet, and Claude-in-Chrome. BragJack isn't 'prompt injection fanfic' — it's Prompt Forcing: the extension hands the agent the whole prompt and rides its privileges (files, history, screenshots, even cam/mic on Chrome)."

实用点

如果你的 agent 跑在浏览器里，扩展白名单事实上就是控制平面。需要明确：哪些 agent 能改状态、谁能吊销授权、停止动作是"撤销 grant"而不是改一版 AUP。对做浏览器内 agent 的团队，这是权限模型设计题，不是提示词题。

02 行业趋势

恶意 npm 包绕过 install-script 检测，把 loader 藏在运行时（indexed-btree 等）

"Malicious npm packages just walked past install-script defenses by hiding in runtime. indexed-btree (and friends) looked clean at install — the loader lived in BTree.prototype.set(). Two million weekly downloads of 'looks fine.' Install scanners ≠ stop. Runtime behavior needs an owner who can yank the package mid-call."

实用点

安装期扫描对运行时注入无效。供应链防护需要补运行时行为监控 + 能在调用中途撤包的能力。对依赖树深的项目，值得检查是否对高下载量但低维护的包做了运行时观测。

03 行业趋势

Claude Opus 5 被用于把 Discourse 图片漏洞串成 OpenAI 员工 ChatGPT/Codex 账号访问

"Claude Opus 5 helped researchers chain a Discourse image bug into OpenAI staff ChatGPT/Codex accounts in under 72 hours. Not a 'patch Discourse' story. Shared SSO turned a low-trust help forum into GitHub/Slack/repo blast radius. Identity architecture owns the stop — not the forum CVE."

实用点

重点不在单个 CVE，而在共享 SSO 把低信任论坛放大成代码仓库爆炸半径。做身份架构时，低信任服务的 SSO 授权范围应单独评估，别默认继承主身份。

04 工具更新

Grok 4.7 一日实测：严格跟随 system prompt、行为稳定、偏保守、更慢更贵

"it follows system prompt very, very closely... it's very 'stable'... it's a conservative model — it doesn't like to take actions without asking... it's a bit slower and costs more than 4.5, visibly."

实用点

作者称 4.7 是首个把其 system prompt 中"要求确认高风险操作"这类指令显性执行出来的模型，说明指令遵循度可作为选型维度。代价是延迟与配额消耗上升。另有用户称其连续工作 70+ 小时、500k 上下文对技能选择/工作流有帮助。
