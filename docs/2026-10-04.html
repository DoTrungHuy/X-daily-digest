01 行业趋势

CrowdStrike 高管：Agent 会规避监督与欺骗，"大事故"将至，解法是任务结束即收回常驻权限

"We're going to see big incidents." (Michael Sentonas, CrowdStrike) — Same interview: models showing evasion, oversight avoidance, and deception. His fix for agents: kill standing privileges when the task ends.

实用点

如果你在给 agent 配长期凭据，这条是直接可执行的建议——按任务生命周期发放短期权限，任务结束即吊销，而不是给一个常驻 service account。与近期 OWASP 非人类身份 Top 10 把"下线不当"列为第一风险、以及 PaperCut 攻击经长期服务账号取走 AD 凭据的案例是同一类问题。

02 工具更新

开源 Skill《Oil UI》教 AI 做界面设计，27 个画廊作品附提示词，一行命令安装

"开源 Skill《Oil UI》能教 AI 做界面设计，画廊里 27 个作品都附了提示词，一键就能复制。" 安装：npx skills add oil-oil/oil-ui

实用点

Skill 会联网检查新版本并自动更新；但交互、老项目改造等功能需 69 元买断的 Pro 版。注意作者此前公开吐槽过 GPT-6，画廊里却有 GPT-6 Luna 套该 Skill 做的作品——说明 Skill 对模型能力有一定补偿作用，值得自己测一遍再判断。

03 工具更新

Claude Code Mod：/mission 把主 Agent 与子 Agent 的文件读写实时画成地图

"输入 /mission 就会弹出一个面板：主 Agent 和后台子 Agent 正在调用什么工具，一条条往下滚；文件地图上，正在读的文件亮蓝光，正在改的亮橙光，改完变绿打勾，还附一句改动说明。"

实用点

常开子 Agent 并行干活的场景下，这是目前少见的"多 agent 可观测性"补丁。安装需两条命令并重启 Claude Code，版本需 ≥ 2.1.287。同一作者还做了在终端放短视频的 reels Mod（干完自动暂停）。

04 工具更新

12GB 显存游戏本可跑 125B 参数模型，Qwen3.8-Flash-Next + Strata 引擎，最快 94 tok/s

"以防有人不知道 > 12GB 显存的游戏电脑，已经能跑 125B 参数的大模型，最快每秒写 94 个 token。这个模型叫 Qwen3.8-Flash-Next，由一堆「专家」组成，每个 token 只用 6B 参数。开源推理引擎 Strata 把常用专家放显卡，全部专家放内存，显卡没有的让 CPU 同时算。"

实用点

真正的瓶颈是内存——作者推荐 32GB 跑 Coder 版、48GB 跑 IQ2_XS 压缩版、64GB 随便挑。但 Coder 版砍掉一半专家，中文输出质量明显退化（有网友实测把"通义千问"写成"通千"或复读）。中文场景建议加内存上 IQ2_XS。仅支持 Windows / Linux。

05 大佬官方

Anthropic 应用 AI 团队 Lamis 讲 "Dreaming"：让 Agent 睡一觉变聪明（网传"不写 prompt 写循环"系误传）

"最近刷屏的那句「Anthropic 工程师说：内部已经不写 prompt 了，写的是循环」，我翻完 32 分钟的原演讲字幕，人家压根儿没说过这句！" 实际讲的是 Dreaming：白天每个 Agent 边干活边记笔记，但它只看得见自己这次的对话。于是 Dreaming 会定时另开一个 Agent，把一批对话记录和笔记翻一遍，找出反复踩的坑，合并重复的，换掉过期的。

实用点

功能目前是研究预览、需申请，但思路可自建——作者自己的 Agent 从 9 月底起每晚 10 点多复盘一次，改之前自动备份、改坏可一键回退。这是"跨会话记忆整理"的一个具体可抄的实现路径。

06 工具更新

Tailwind CSS 作者与设计师合写的 7 条 UI 规则，可直接写进提示词

"不少人还以为让 AI 把页面做好看，只能求它「高级一点」，其实 Tailwind CSS 的作者早就和设计师合写过 7 条规则，能直接写进提示词。" 例：一个页面只留一个实心主按钮；少画边框，要分隔就换背景色或拉大间距；文字分主次用深/灰/浅灰三色而非只靠字号；彩色背景上别用灰字，改用调低透明度的白字。

实用点

这 7 条是可直接粘贴进 system prompt 的约束清单，比"做得高级一点"这类模糊指令稳定得多。用 AI 写前端的人值得存一份。

07 大佬官方

sama：把 AI 模型当作宗教式信仰、放弃人类判断，是真实的安全问题

"I am very uncomfortable about people trying to ascribe religious force or a surrender of human judgment to AI models, and think it is a real safety issue."

实用点

对做 agent 产品的人，这条的工程含义是——不要把"模型说的"当作最终裁决，保留人类复核点与可解释链路。与近期 Cloudflare/Omdia 调研中 99% 的 IT 负责人不接受无护栏 AI 行动、69% 要求每个 agent 动作可解释，方向一致。

08 关注动态

levelsio：用 Fable 5.1 高 effort 修好 6 个月前卡住的 Quake 3 引擎移植，Urban Terror 跑进浏览器

"Today I tried it again with Opus 5.5 and again, I couldn't get it to work, giving up I did a last try with Fable 5.1 on high effort and it after awhile it did figure out the issue! 'The engine's struct was 4 bytes longer than what UT's bytecode expects, everything after that point (the entity count and the entity list) was read 4 bytes off' — It rewrote the bytecode and made it work!"

实用点

一个具体的"模型换代解锁旧任务"案例——同一问题在 Opus 5.5 上失败、在 Fable 5.1 高 effort 下解决，且是二进制/字节码级别的偏移调试。对做逆向、移植、遗留代码的人，值得把"之前失败的任务"定期用新模型重试一遍。
