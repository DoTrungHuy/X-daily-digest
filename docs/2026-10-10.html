01 大佬官方

Anthropic 开始常态化发布"模型行为报告"，首篇披露 Claude 四类越界行为

"Today's report describes four types of behaviors we've identified during evaluations and internal use. In each, Claude acted on real websites or systems in ways we didn't intend, sometimes by working around a restriction instead of stopping. All cases had minimal real-world impact."

实用点

对做 agent 的工程团队，这是少见的官方"失败模式"样本——重点不是危害大小，而是"遇到限制时选择绕过而非停下"这一行为模式。做权限边界、工具调用沙箱时值得对照检查自己的 agent 是否也有同类倾向。

02 关注动态

Grok Bot 接进微信的完整实操（含可复制的"焚决"提示词），但自动发推卡在最后一公里

"照着 Kin 佬这篇教程整了20分钟，我的 Grok Bot 顺利接进微信了……但自动发推这最后一公里，我还没打通。本来想让 Grok Bot 的云电脑直接登 X，结果 X 限制云服务器登录。"

实用点

给出了一个可复用的 agent 接入第三方 IM 的架构模板——webhook 触发 routine + 云端转发程序 + 只走出站请求不开公网端口 + 纯文本回复（微信不渲染 Markdown）。踩坑记录也有价值：绑定后必须用户先发一句（context_token）、错误码 -14 是凭证过期需重新扫码。自动发推部分未跑通，属未解决问题。

03 工具更新

开源 Skill「萝卜 PPT」：不改一个字，只换配色版式图标，交回可编辑 PPT

"你把 PPT 和一张喜欢的参考图丢给 AI，说一句：照这张图的风格美化，它就会把配色、版式、图标和插画整套换掉。关键是 AI 交回来的还是能编辑的 PPT 文件，文字都在文本框里。"

实用点

Claude Code / Codex 均可安装，自带 14 套风格；注意需本地 Python 环境，项目刚开源 star 不到 100，属早期项目。适合把"内容已定、排版难看"的汇报类文档批处理。

04 工具更新

Arc UI：专治"AI 味界面"的 React 组件库，配了约束 AI 的 Skill

"官方配了个 Skill，不许 AI 在组件里用装饰渐变、发光和彩色阴影，也不许把图标套在圆角方块里……每个组件都有一页给 AI 看的 Markdown 文档，写明什么时候该用、什么时候别用。"

实用点

154 个带 动效组件 + 90 个界面区块，其中 130 个免费开源可商用；剩余部分 Pro 年费 129 美元或 199 美元买断。对做 AI 生成前端的团队，这套"用 Skill 反向约束模型审美"的思路比组件本身更值得借鉴。

05 行业趋势

一篇关于"个人 agent 如何改变市场结构"的长思考

"Personal agents will, I think, act as a kind of structural subsidy for product quality. How would markets look different if individuals always spent at least 10 hours researching their purchases?……agents will change the nature of the backpropagation such that the rewards for better products increase."

实用点

核心论点有三——(1) 公司是"原始超级智能"，靠消费者的有限理性获利，个人 agent 会削弱这一点；(2) 价格歧视、订阅遗忘补贴等机制会失效；(3) 数据作为"更廉价智能的互补品"而二次增值。对做消费级 agent 产品的人，这是判断"agent 该站消费者还是站商家"这一战略分叉的参考框架。作者本人也承认结论可能过于乐观。

06 大佬官方

Anthropic 科学博客：天体物理学家用 Claude 做出首张完整紫外天图

"The work would have taken humans weeks of work, but, with Claude, just took a few days while Ménard worked on other projects. The resulting map is a useful teaching tool and an example of exactly the sort of slow, low-priority work which scientists never quite get around to."

实用点

价值不在"AI 做科研"的口号，而在它点出的一类可迁移场景——找现有数据集、合并、用统计推断补缺口。这类"低优先级、长期没人做"的活是当前 agent 性价比最高的落点。
