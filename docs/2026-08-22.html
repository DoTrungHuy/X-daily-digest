03 工具更新

ChatGPT 本周功能更新：快捷附件、时间感知、长对话提速

"1/ Recent photos: Long press on + menu to quickly attach recents on iOS... 2/ Time: We made it so ChatGPT better understands your current time... 3/ Long convo loading: Long conversations load and run faster... 4/ 'No internet' errors: We show clearer updates in the UI when you’re waiting for an internet connection."

实用点

时间感知改进对 agent 开发者尤其重要——此前 ChatGPT 对当前时间的理解存在缺陷，可能导致依赖时间逻辑的任务出错；现在修复后，基于 ChatGPT 构建的自动化流程在时间相关场景（如定时任务、日程处理）会更可靠。长对话提速也直接改善多轮 agent 交互体验。

04 工具更新

Cloudflare 推出 Bot Preference Sync：自动同步 robots.txt 与 AI 爬虫偏好

"Cloudflare's new Bot Preference Sync keeps your robots.txt automatically aligned with whatever AI bot preferences you've already set in the dashboard — Search, Agent, and Training. No more maintaining a static file. Set it once. We keep it in sync."

实用点

对运营网站或 API 的开发者，这是治理 AI 爬虫访问的实用工具——在 Cloudflare 面板设置一次偏好（如允许搜索爬虫、限制训练爬虫），robots.txt 将自动更新，无需手动维护静态文件。适合需要精细控制 AI 数据抓取的团队。

05 关注动态

Devin 在 Slack Code 中的多人协作实战：自动接任务、开 PR、拉设计师

"Devin follows the work as it happens, picks up a task from the engineering channel, opens a PR with a demo video, and brings in a designer to finish the UI. All without leaving Slack or waiting to be tagged. The agent isn’t off doing its own thing. The whole team is right there, building with it."

实用点

这是 agent 与人类团队协作的典型范式——agent 不再孤立运行，而是嵌入现有沟通流（Slack 频道），主动认领任务并产出可审查的成果（PR + 演示视频）。对正在设计 agent 工作流的团队，可参考这种“频道内协作”模式，减少上下文切换成本。
