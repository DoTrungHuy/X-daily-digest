01 大佬官方

OpenAI 公开 Control Room：统一追踪研究推理负载，35 秒内可掐断模型输出

“We built Control Room, a central system to track model workloads across our research infrastructure and stop them quickly when safety or security concerns arise… halts model output within 35 seconds of a decision to intervene to stop or pause a job.”

实用点

对做 agent 平台的团队，这是一个可参考的“kill switch + 负载可观测”架构范式：把训练/评测/数据处理的所有推理负载纳入同一注册表，并与错位监控系统联动；35 秒是值得对标的干预延迟量级。

03 工具更新

Dots 支持把多台本地机器接入同一个 dot，按任务选择执行机

“You can now connect multiple local computers to the same dot and choose which one it uses for a task. It can build and test your app on a dedicated machine while you keep coding on your laptop.”

实用点

本质是“agent 执行环境与开发机解耦”，适合把构建/测试这类重负载丢给专用机器，避免占用本地交互；对多机开发环境（台式 + 笔记本 + 家用服务器）的 agent 工作流有直接价值。
