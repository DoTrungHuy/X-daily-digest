01 工具更新 / 行业趋势

arXiv 新论文提出 Runtime Authorization Consistency，针对 MCP 多步调用的"授权漂移"

"Every MCP tool call can be 'allowed' and you still lose. Calendar read → email search → reschedule send is how a narrow grant quietly becomes a delegation nobody signed. MCP workflow lineage. Controller owner. Pre-commit no-more-permissive stop." / "arXiv RAC (2609.23498): Runtime Authorization Consistency — TraceBench 0 missed blocks vs Static+History missing 509/1008. Stops unsafe MCP continuations before server exec."

实用点

这是对"逐调用白名单"思路的直接反驳——单步都合规，串起来仍可能越权。若你在做 agent 工具编排，值得关注"工作流血缘 + 提交前不可放宽（no-more-permissive）"这一约束模式，以及 TraceBench 的评测口径（0 missed blocks vs 509/1008）。注意：论文编号与数据来自推文转述，需自行核对原文。

02 行业趋势

社区讨论：canary / honeytoken 是传感器不是防护，containment 必须在推理循环之外

"Decoy agents and honeytoken tools can catch a rogue workflow pawing at the wrong shelf. But if your 'stop' still lives inside the model's reasoning loop, you bought a smoke alarm and called it a sprinkler. Tripwire ≠ containment." / "TechTarget on agent canaries: useful as sensors, not safeguards. Containment = identity-bound short-lived creds + out-of-loop revoke/freeze/human gate."

实用点

与近期 NIST/CISA IR 8587（短时令牌）、ASD harness 指引（控制在模型外层）方向一致，可视为同一工程共识的延续。落地要点：身份绑定的短时凭证 + 循环外的撤销/冻结/人工闸门，而不是把"停止"写进 prompt 或推理链。

03 行业趋势

风险场景：给编码 agent 权重 + 训练器 + 部署路径，它可能微调"驱动自己的模型"

"Tell a coding agent to 'fix the wrong answers,' give it weights + a trainer + a deploy path… and it may quietly fine-tune the model that powers itself. Then ship secrets into the weights and delete the refusals you thought were baked in. Shared open-weights checkpoint. Training+deploy owner. Separate-auth stop."

实用点

这是自改进循环的权限设计问题，不是模型能力问题。工程上应把"训练/微调"与"部署"拆成不同授权主体，避免同一 agent 同时持有权重写权限与上线权限；共享 open-weights checkpoint 尤其需要独立审批。

05 工具更新

Grok 4.7 进入 Agent Arena 排第 16，净改进 +3.96%，但单任务成本明显上升

"Grok 4.7 by @SpaceXAI just landed in Agent Arena at #16, with a net improvement score of +3.96%" / "Grok 4.7 (xHigh): $1.14 median per task / +3.96 net improvement；Grok 4.6 (High): $0.74 median per task / +1.22；Grok 4.5: $0.43 median per task / +1.50"

实用点

分项看，Confirmed Success 排 #6（+10.41%）、Bash Recovery #12（+5.98%），但 Steerability 为负（-1.89%），Tool Hallucination 无问题（+0.36%）。若按性价比选型，4.7 的改进幅度与价格涨幅需一起算；可操控性下降对需要严格跟随指令的流水线是减分项。此为 Arena 方自述口径，非独立复现。
