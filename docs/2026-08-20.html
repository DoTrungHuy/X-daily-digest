01 工具更新

Claude Code 新增 Concise 输出风格：结果优先，细节按需

"You can now set Claude Code's output style to Concise. Claude leads with the result, keeps responses short, and still gives full detail when you ask. Turn it on in /config → Output style, or set 'outputStyle': 'Concise' in settings.json."

实用点

对日常使用 CLI agent 的开发者，Concise 风格可显著减少长输出噪音，适合快速迭代场景；可通过 settings.json 全局配置，便于团队统一风格。

02 工具更新

Claude Managed Agents 三连更：Self-Hosted 内存、域名控制、多 agent 会话查看器

"We shipped three updates to Claude Managed Agents. First, we made it easier to use memory with Self-Hosted Sandboxes... Second, we've added domain controls. web_search and web_fetch now take allowed_domains or blocked_domains... Finally, we've redesigned the Console session viewer for multi-agent sessions. It now has a minimap with one lane per agent, a streaming transcript grouped by agent iteration, and an inspector with cost in dollars per thread and per session."

实用点

域名控制（allowed_domains/blocked_domains）对生产环境 agent 的合规与安全至关重要；多 agent 会话查看器按 agent 分 lane 展示并统计每线程/每会话成本，便于调试与成本优化。

05 工具更新

Grok Build v1.0.7：工作流目录、Always/Never 权限、循环工具调用加速中断

"Grok Build just got a new update bringing a first-class workflows catalog, Always and Never allow on permission prompts, a live status line that can refresh on a timer, and faster shutdown of looping tool calls... Permission prompts now show 'Always allow' and 'Never allow' options by default... Tool call loops are interrupted earlier to avoid wasting time on repeated identical actions."

实用点

Always/Never 权限持久化（含 MCP 工具与 web-fetch 域名）大幅减少交互打断；循环工具调用提前中断可节省 token 与时间；/workflows 命令与目录便于管理复杂工作流。

06 大佬官方

OpenAI 预览 Private Safety Processing：Zero Data Retention 与安全监控兼得

"Today we're previewing Private Safety Processing, designed to let us keep offering Zero Data Retention while improving our safeguards... For ZDR deployments, content stays on infrastructure the customer controls. Automated systems look for patterns across related interactions and return limited safety signals, without exposing the underlying prompts or responses to OpenAI employees (even me!). We're also developing an OpenAI-hosted option encrypted with customer-controlled keys... plan to begin rolling it out in September."

实用点

对使用 ZDR 的企业客户，Private Safety Processing 在不牺牲数据控制权的前提下增强跨交互风险识别；9 月将开始推出，值得关注密钥托管选项的细节。
