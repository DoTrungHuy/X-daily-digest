01 关注动态

levelsio 用 Claude Code 把《战地 1942》反编译并移植到 Web + WASM，含多人联机

“it disassembled the x86 raw machine code to find 57,000 x86 functions / it translated each x86 function into a C function / it outputed 100,000 lines of C / it then compiled that to WebAsswmbly with Emscripten”

实用点

这是一条完整的“无源码遗留二进制 → 可运行 Web 应用”流水线样本：反汇编定位函数、逐函数翻译为 C、Emscripten 编译、把 300 多个 Windows/Direct3D 调用重写为 WebGL2/OpenGL、再自建 WebSocket 网络栈。对做逆向、移植、WASM 工具链的人有参考价值；作者也说明 6 个月前尝试失败，这次换 Opus 5.5 重试才成，说明模型能力边界在变。注意这是免费 shareware demo，非完整游戏。

02 关注动态

levelsio 给出该移植的 token 成本：约 100 万输出 token，API 价约 100 美元

“cost me 1 million output tokens / At API prices that's about $100 / But I pay $100/mo Claude”

实用点

给“agent 做大型重构/移植”提供了一个粗略成本锚点：百万级输出 token 对应百美元量级。对评估自建 vs 订阅、以及给 agent 任务做预算上限有直接参考。另有一条后续说明多人部分曾卡住（“hit a bump decompiling the multiplayer part”），说明这类任务仍需人工介入排障。

03 大佬官方

OpenAI 扩大漏洞赏金：关键发现最高 17.2 万美元，并与 Cathedral Systems 合作做内部安全冲刺

“We're planning our next internal security sprint at OpenAI and partnering with Cathedral Systems... We're also raising bug bounty rewards, including more than quadrupling rewards for critical findings. Exceptional findings will be eligible for up to $172,000”

实用点

两个可操作点：一是关键漏洞奖励翻四倍以上、上限 17.2 万美元，安全研究者可重新评估投入产出；二是官方明确“过去 30 天内已发奖励若符合新档位会补差价”，历史报告也值得复查。对做 AI 辅助漏洞挖掘的团队，这是“防守方先用 AI”的明确表态。

05 大佬官方

OpenAI 发布 LifeVal 基准：按数千名 ChatGPT 用户反馈定义“日常任务”能力

“we built LifeVal, a new benchmark shaped by feedback from thousands of ChatGPT users on where they most want help from a personal assistant—from finding childcare to accessing government services to managing personal finances.”

实用点

把评测从学术题转向“找托儿、办政务、管个人财务”这类真实任务，对做 agent 产品的人是一个评测维度参考：你的 agent 是否能在这些高频生活场景闭环，而不是只跑 benchmark 分数。官方称已用该基准迭代模型一年。
