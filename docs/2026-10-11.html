01 工具更新

Claude Projects 上线：一段话自动拆成多线程，云端并行跑

"以前让 Claude Code 同时干几件事，得开几个会话挨个交代，现在丢一段话，它居然自己分好活了……这个功能叫 Projects，官方演示里 Claude 一口气拆出 8 个线程，在云端同时跑，合上电脑也不停。"

实用点

多 agent 编排从"自己写 orchestrator"变成产品内置能力，值得重新评估自建调度层的必要性。注意两点成本陷阱：新项目默认每线程用 Opus 5.5，多线程并行会快速消耗额度；额度耗尽后线程会等重置再继续。任务不复杂时先在项目设置里把线程模型换成 Sonnet 5.5。目前仅网页/桌面/手机 App 可用，终端与 VS Code 插件不支持。

02 工具更新

Google AI Edge Foresight：免费 Mac 会议笔记 App，全程本地

"开会时你只管随手记几个关键词，它会根据实时转录，把这些词扩写成完整的笔记……录音、转录和导入的资料都只留在你的 Mac 上，模型下好后断网也能用。"

实用点

本地推理 + 实时转录 + 关键词扩写是一个可复用的产品形态，对做端侧 agent 的人有参考价值。限制明确：实验版，仅 Apple 芯片、macOS 14.2 以上，官方未说明中文会议转录准确度。竞品 Granola 查 30 天前记录需每月 14 美元，本地存储是差异化点。

03 工具更新

/ketchup：前 Cursor 工程师把"我离开后发生了什么"做成 Skill

"用大白话说说我上条消息之后都有哪些进展，有要我处理的事，给我一段够我拍板的摘要……敲一下 /ketchup，AI 就会先说有几件事等你拍板，再按轻重讲进展，要你决定的事还会附上选项、代价和它的建议。"

实用点

多会话并行时"状态回收"是真实痛点，这个 Skill 的解法是把摘要格式固定为"待决策项 → 按轻重排序的进展 → 选项+代价+建议"。在 Cursor 官方插件 pstack 里，只有一个 Skill 文件，复制到自己的 Skill 目录即可用；Codex 里需输入 $ketchup 调用。

04 工具更新

5 个现成 Agent / Skill 仓库汇总，含 Anthropic 官方 knowledge-work-plugins

"写代码的，用 agent-skills，25 个 Skill 从写需求管到上线，一行命令就能装；做销售、客服、财务的，装 Anthropic 官方的 knowledge-work-plugins；做自媒体的，去 agency-agents 里翻。"

实用点

作者给了一条容易被忽略的工程约束——"Skill 简介每轮都占上下文，装多了 Claude Code 还会丢掉一部分简介，AI 就不一定挑得准了"，即 Skill 数量与选择准确率存在权衡，建议先装一个。这条对设计 Skill 加载策略的人比仓库清单本身更有用。

05 行业趋势

Google 试点面试允许用 Gemini：考"代码理解"而非刷题

"在「代码理解」这一轮，面试官会给你一份现成的代码，让你读懂、排错、优化，同时看你提示词写得准不准、会不会调试……AI 写错了还得你自己揪出来。"

实用点

如果这一试点扩大，面试评估维度会从"能否写出算法"转向"能否审查 AI 产出"，即读代码、定位错误、写有效提示词。对求职者的直接含义是刷题之外需要练代码审查与调试表达。

06 关注动态

Tibo 28 天挑战第 6 天：全员额度重置

"Day 6/ Reset……Global reset by EOD. 今天结束前全员重置。"

实用点

这是此前"28 天军令状"的后续进展（此前为"每天要么上线明显改进，要么重置额度"）。推友观察重置周期已缩到 4~5 天，若按此节奏，每天需用掉 20% 以上额度才不亏。对重度用户意味着可以更激进地跑长任务，但节奏不可预测，不宜把工作流建立在重置预期上。

07 行业趋势

levelsio 复盘两年"怀旧项目"：AI 辅助逆向 + WASM 让老系统进浏览器

"I spent 6 months trying to reverse engineer Windows XP to run on v86, very difficult (because it's so big) and only possible because modern AI like Opus 5.5 is good enough to figure that out……yesterday 80,000 people played around in Windows 3.1 or Windows XP inside their browsers."

实用点

一个具体的能力边界样本——AI 辅助逆向工程让"把大型老系统移植到 WASM"从不可能变为可行，且配合 WebSocket 可做多人交互。对做浏览器端模拟、兼容层、逆向工具链的人有直接参考。作者明确该项目非商业、不盈利。
