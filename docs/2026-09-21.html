01 行业趋势

NIST + CISA 敲定 IR 8587：agent 签名令牌按特权凭证管理，建议上限约 1 小时

"if your AI agent holds signed access tokens, treat them like privileged credentials — short TTL, protected signing keys, real revoke. Classify agent tokens as access control, not chat state. Name the identity owner. Stop = kill live agent sessions when the lease ends." / "recommended agent token ceiling ~1 hour."

实用点

如果你在给 agent 发 token，现在就该把 TTL 压到小时级、把签名密钥纳入 KMS/HSM 类保护、并实现真正的吊销路径（而不只是等 token 自然过期）。"agent 活得比 token 久"等于一张被偷的工牌——这是可以直接写进设计评审 checklist 的一条。

02 行业趋势

ASD 发布 agentic AI harness 指引：prompt injection 在模型内无可靠修复，控制放在模型外层

"prompt injection has no reliable fix *inside* the model. So Stop doesn't live in the weights. It lives in the harness — least privilege, scoped tools, human refuse on high-impact acts."

实用点

把安全预算从"模型对齐"转向 harness 工程：最小权限、工具作用域收窄、高风险动作保留人工拒绝权。对 agent 开发者而言，这是把"能不能拔插头"具体化为"谁能在负载下撤销工具授权"。

03 中国相关

ZCode 安全事件后续：官方完成修复并开源，CAICT 与绿盟出具评估结论

"we have completed the necessary remediation and sincerely apologize to all our users. We have open-sourced ZCode..." / "CAICT confirmed that the zcode-prod Alibaba Cloud OSS bucket is in a zero-data state... The Repo Wiki feature has been removed" / "NSFOCUS confirmed that all data objects in the zcode-prod Alibaba Cloud OSS bucket, as well as the bucket itself, have been deleted."

实用点

这是此前"静默打包上传用户仓库"事件的实质进展——新增信息是 v3.14.0 客户端移除 Repo Wiki 入口与本地仓库快照生成/上传工作流、OSS bucket 已删除、两家机构出具评估。官方同时承诺建立漏洞上报与响应流程并给奖励。对使用该工具的团队，值得核对版本是否已升到 v3.14.0。

05 工具更新

Grok Bot 接入 X Money，可用自然语言直接发起付款

"I can now send $ money to someone just by telling my bot what I want to do... I just type the instruction in plain English and Grok Bot handles it through 𝕏 Money, and the payment immediately goes through." / "your Grok Bot handles the work through whatever financial account, while you stay in control of the approval."

实用点

06 行业趋势

EU AI Act 将 agentic AML/金融犯罪合规系统列为高风险，同期两家合规平台融资

"agentic AML gets stamped high-risk under the EU AI Act... Classify the agent as high-risk. Name the bank/deployer who owns Tuesday. Stop is a human who can kill outbound cases same-second — not a Series B slide that says 'human oversight.'" / "Bretton AI (~$75M) and Napier AI (~£45M) raises into that exact bar."

实用点

做金融合规 agent 的团队，监管分类已明确落在高风险档，需要能指名"谁负责、谁能在同一秒掐断外发案件"，而不是在 PPT 上写"human oversight"。融资规模不等于冻结席位。

07 行业趋势

Connecticut 与 Maryland 新规：AI 不能作为雇佣决策歧视的抗辩理由

"Oct 1, Connecticut: 'AI is not a defense.' If an employment decisioning tool (AEDT) discriminates, the employer still owns it — you don't get to blame the screener." / "Connecticut PA 26-15 / CFEPA amendment — Automated Employment-related Decision Technology shall not be a defense (effective Oct 1, 2026). Maryland HB 895 same day."

实用点

用 AI 筛简历/做雇佣排序的团队，责任归属已明确落在雇主一侧。需要能提供决策 trace 作为证据，而不是"模型这么说的"。对做 HR tech 的开发者，这是合规需求清单的直接输入。
