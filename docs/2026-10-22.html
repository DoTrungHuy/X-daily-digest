01 大佬官方

OpenAI 披露 PHP 高危漏洞并发布 Codex 自查 skill，PHP 生态进入紧急修补期

“OpenAI models helped researchers—operating as part of our Patch the Planet initiative—discover critical security flaws in PHP... Every site using PHP can now safely upgrade their version to stay secure.” / “we have packaged a Codex skill to help check. Point your Codex at this repo.”

实用点

跑 WordPress / Laravel / MediaWiki / Magento / Joomla 的团队应立即升级 PHP 版本并跑一遍该 Codex skill 做自查；这是“AI 先于攻击者找到漏洞”的防守窗口案例，也说明把安全扫描做成 agent skill 是可复用的工程模式。

GitLab 曝 CVSS 10.0 未授权 RCE，自托管实例受影响

“GitLab also dropped a CVSS 10.0, which is the highest score they give out, for a bug that's been there since 2014, so that's every self-hosted GitLab for twelve years.”

自托管 GitLab 的团队需按官方公告确认版本并升级；结合同日 PHP 事件，建议今天统一做一次“补丁 + 密钥轮换”清单。

03 工具更新

LiteLLM 1.107.0 PyPI 包与 Docker 镜像被投毒，含凭据窃取与后门

“LiteLLM 1.107.0 got hijacked and shipped a credential stealer and a remote access trojan in every single wheel and the Docker images, including latest... just installing it was enough.”

实用点

凡在 CI 或生产环境装过 LiteLLM 1.107.0（含 latest 镜像）的，应视为凭据已泄露，立即轮换所有相关 API key 并审计出网流量；依赖锁定版本 + 校验哈希是必要防线。

04 行业趋势

Railway 平台环境变量被解密，官方暂停全部部署

“Railway paused every deployment on the entire platform because someone got into the environment variables, so now everyone has to rotate every secret they've ever stored there.”

实用点

在 Railway 上托管过服务的团队需轮换全部 secret（数据库密码、第三方 API key）；这也是提醒——把长期凭据放在托管平台的环境变量里，单点失守即全盘失守。
