今日材料里最值得工程侧注意的是 OpenAI 与 Cisco 联合开源的 Linux 运行时 Shirudo（agent 写 eBPF 动态防护、不停机挡漏洞），以及 GPT-6 Cyber 一次性验证 948 个可提权的 Linux 内核 bug；其余多为产品小更新与观点类内容，噪音比例偏高。

01 工具更新

OpenAI × Cisco 开源 Shirudo：让 agent 用动态 eBPF 给系统打“临时护盾”，不必停机等补丁

“We're introducing Shirudo, an open-source Linux runtime allowing agents to defend systems without downtime. It lets agents write dynamic eBPF controls to shield systems from exploits, giving defenders more time to test and roll out patches. Built by @cisco together with OpenAI.”

实用点

思路是把“漏洞窗口期”从被动等待补丁变成 agent 生成 eBPF 规则临时封堵；对做 agent 安全、运行时防护、eBPF 可观测/拦截的团队是可读的开源参考实现，也提示 agent 写内核级策略需要怎样的沙箱与审核流程。

02 大佬官方

GPT-6 Cyber 单次运行验证 948 个可本地提权的 Linux 内核 bug 并生成补丁

“In one run, GPT-6 Cyber helped us validate 948 Linux kernel bugs that could grant local root access and generate patches for review. Our researchers @clintgibler and @ky1ebot share their findings and how they worked with maintainers to get fixes upstream.”

实用点

这是“模型 + 维护者流程”的漏洞挖掘案例，重点不在数量而在补丁如何 upstream；对做安全自动化、漏洞复现与补丁评审流水线的团队有参考价值，也说明 agent 产出仍需人工/维护者复核。

@OpenAI 原文1
03 行业趋势

OpenAI 与 Cisco 合作定位为“agent 时代的安全基础设施原语”

“We're working with Cisco on what we think are going to be key infrastructure primitives in the new era of cybersecurity. Everything needs to be built to be operated safely by aligned agents at machine speed.”

实用点

与 ITEM1 同源的表态，指向一个设计约束——未来基础设施要默认“由 agent 以机器速度操作且安全”；做平台/基础设施的团队可据此评估自身权限模型与审计粒度。

04 工具更新

Antigravity 上线进度清单：实时追踪 agent 每一步，可展开完整分解

“No more guessing what your agent is doing mid-run. Progress checklists are now live in Antigravity. Track every step in real time, and expand the full breakdown whenever you want to double-check the work. Built from your feedback, and we are just getting started.”

实用点

agent 长任务的可观测性从“日志”走向“结构化 checklist + 可展开明细”，是评审 agent 输出时的实用交互模式；做 agent UI/评测的可以借鉴这种“步骤级可核查”设计。

原文1
05 工具更新

OpenComputer：开源编码 agent，在 Slack 线程接任务、在自己的机器上开 PR

“OpenComputer is an open-source coding agent that takes tasks in a Slack thread and opens a pull request, on its own computer.”

实用点

把入口放在 Slack、出口放在 PR，是团队内落地编码 agent 的低摩擦形态；可对照自建方案评估其隔离执行环境与 PR 生成质量（材料未给出更多细节）。

原文1
06 工具更新

Apprise：一条命令、一种 URL 格式，把告警推到多个聊天/推送服务

“Your alert script shouldn't need a different tool for every chat and push service. Apprise sends one notification to many services from a single command, using one URL format.”

实用点

运维/agent 告警通知的统一出口，减少为每个 IM 渠道写适配器；适合接在监控脚本或 agent 任务完成回调后面。

07 关注动态

levelsio 谈“扰动幂律”：少数人制造多数噪音，执行规则本身才有效

“You see this power law in every community, both online and offline. A small % of people is responsible for the majority of disturbances. Which is why just enforcing the rules and removing those people is so effective. But we live in a time were simply doing that is frowned upon”

实用点

与其说是 AI 话题，不如说是社区/产品治理经验；对做 UGC、评论区、agent 生成内容审核的团队，是“少量高频违规者优先处置”的经验佐证（非量化结论）。
