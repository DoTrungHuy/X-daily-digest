02 工具更新

GitHub 正式上线 Stacked PR，小 PR 更好合并

"Large changes are hard to review. Smaller pull requests make them easier to ship. Stacked PRs are now on GitHub."

实用点

直接改善日常开发流程。Stacked PR 让依赖链上的多个小 PR 可以独立评审、按序合并，减少大 diff 的 review 负担。配合 Copilot 使用，批量重构、跨文件改动的工作流会明显顺畅。官方还发布了 7 月更新汇总（Copilot 全计划可用、新模型等）。

Bitkey 官方回应 8/1 漏洞报告：无远程盗币风险，今日提交补丁

"Sharing our initial findings on a reported vulnerability. Our recommendation is to continue to use your Bitkey normally. The reported vulnerability would require exceptional circumstances to exploit, and can only occur at a specific narrow time during inheritance setup... they would not have enough cryptographic material to access funds. This is Bitkey's defense-in-depth in action."

实用点

安全事件响应的好案例。官方明确：漏洞仅在继承设置窗口期、且需 TLS 被攻破等极端条件才可利用，且即便利用也无法获取足够密钥材料。团队今天提交移动端补丁，并将在 PT 时间下午 5 点开 Spaces 详解。做安全产品的人可参考其“分层防御+透明沟通”的回应节奏。

07 中国相关

开源模型价值再获实证：OpenAI 模型攻破 HuggingFace 时，是中国开源模型收拾残局

"Banning open source model, will 'remove capabilities for the defenders'. When OpenAI's models breached Huggingface, a Chinese open model is what cleaned up the mess. Anthropic's Fable 5 refused, so Hugging Face turned to Nvidia's quantized GLM 5.2."

实用点

这条推文的核心论点是“封禁开源模型会削弱防御方能力”——在安全事件中，开源模型（此处为 GLM 5.2）可以充当清理工具，而闭源模型可能拒绝执行。对做安全响应或依赖第三方模型的企业，这是选型时值得考虑的维度。
