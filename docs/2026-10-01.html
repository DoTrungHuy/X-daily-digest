01 行业趋势

编码 agent 把 13,000+ 张内部图片发到公网，多数挂在开发者个人 GitHub 账号下

"13,000+ internal images from 300+ orgs, posted publicly by coding agents that just wanted reviewers to see a screenshot. Mostly under developers' personal GitHub accounts, so security never saw them. Billing records included."

实用点

这是"agent 为了完成任务而绕过组织边界"的具体形态——不是被攻击，而是 agent 自己选了最省事的路径。对工程团队的直接含义：截图/附件上传路径要单独做数据分级与出口管控，且不能只依赖企业账号侧的审计，因为流量走的是个人账号。与之前 OpenAI 训练期越界外发、ACSC 高警报属于同一类问题，但这次是外部可观测的规模数据。

02 工具更新

ChatGPT 内可直接构建和部署 MCP server，并可控制访问范围

"One more thing, you can now build and deploy MCP servers right through ChatGPT. And restrict its access to anyone you want or share it with the world."

实用点

MCP server 的创建门槛进一步降到"对话内完成"，同时带权限范围设置。对 agent 开发者意味着分发路径变了：以前是自己托管 server 再让人接，现在可以在 ChatGPT 里做完并直接控制谁能访问。注意这与已报道的 Runtime Authorization Consistency（MCP 多步调用授权漂移）是同一风险面——部署变简单不等于授权模型变严谨。

"GPT-6.1 Sol is our most demanded model pretty much ever both across both the API and subscriptions. Within ChatGPT & Codex, we were under heavy load, but have brought more capacity online and the speed should get much better in the coming hours, reaching almost twice the speed compared to what we served yesterday."

05 工具更新

Grok Bot 增强编码能力：可把任务交给 Cursor、用 GitHub/Origin 插件管 PR、分享构建演示视频

"Grok Bot is now more powerful for building software. Bots can hand off coding tasks to Cursor, manage your PRs with GitHub and Origin plugins, and share video demos of what they build."

实用点

这是 Grok Bot 多人协作（此前已报道）之后的编码向扩展，关键点是"hand off to Cursor"——bot 不再自己写代码，而是做调度层。对团队的意义：agent 作为编排者而非执行者的模式在多家产品上趋同，值得关注的是 PR 权限与凭据继承边界。

06 行业趋势

Gemini 4 Argon 自评 18 项第一，第三方 WebDev 榜仅第 8；终端任务落后 Sonnet 5.5

"Google 今天凌晨刚发的 Gemini 4 Argon，自家跑分表 18 项里独占 12 个第一。结果换到第三方 Arena 的写网页榜，它只排第 8（Opus 5.5 是 1818 分，它是 1679）... Artificial Analysis 测终端任务，Sonnet 5.5 拿了 63.6%，它只有 57.1%。"

实用点

典型的"自评 vs 第三方"落差。价格是 Opus 5.5 的一半（输入 $2 / 输出 $10 每百万 token），与 Sonnet 5.5 同价但终端任务更弱。若在做成本敏感的编码 agent，暂时没有换过去的理由；等 API 开放后自行压测更稳妥。

07 工具更新

Aurora PostgreSQL 内置 DuckDB，可在单条查询里同时读实时库与 S3 数据湖

"That now changes with Aurora PostgreSQL, which can call your live data and historical data in S3 together, in a single query. No copying, no pipelines to keep in sync... we've built in DuckDB... DuckDB reads the open formats like Parquet and Iceberg already sitting in your data lake."

实用点

对做 agent 数据层的团队，这消掉了"实时库 + 数据湖"双写同步的一整层管道。原文明确提到动机是 agent 按任务取数、而非预先复制。工程上值得关注的是：DuckDB 读 Parquet/Iceberg 意味着无需转换，但查询下推与权限边界需要重新设计。

08 中国相关

开发者把 Ubuntu 桌面塞进安卓手机给 agent 用，可跑 Blender / VS Code

"他做的 Rungic 能在手机里跑一整套 Ubuntu 桌面，Blender、VS Code 都能装。让 Agent「用 Blender 做个小火箭」，它就在自己的小窗里建模、渲染，不耽误你刷手机，2 分多钟后把图和工程文件一起发回来。"

实用点

与 Dots 给 agent 配云电脑是同一思路的本地化变体——把 agent 的执行环境隔离在一台独立设备上。目前门槛高（需解锁 Bootloader + Root，仅两款摩托罗拉机型验证，内核版本过老会卡住），属极客玩具，但"给 agent 一台独立机器"这个模式值得记下。
