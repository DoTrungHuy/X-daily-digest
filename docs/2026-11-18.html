01 大佬官方

OpenAI 发布 GPT-6.2 Astra 与 Sol，Astra 主打网络安全能力，Ultrafast 首次下放 Pro 200

“GPT-6.2 Astra and Sol are now available. Super efficient and built to perform where it counts—the real world.” / “GPT-6.2 Astra is our most capable model ever for cyber. It jumps 22 points over GPT-6 Astra on ExploitBench Internal Port.”

实用点

两个模型已进入 ChatGPT Work、Codex（Plus/Pro/Enterprise/Edu）与 API（gpt-6.2-astra / gpt-6.2-sol），Ultrafast 对 Pro 500 双模型开放、对 Pro 200 先开放 Sol。安全侧需注意：因 cyber 能力提升，高风险网络安全请求的拒答更严格，官方称正推动 Daybreak 上的授权防御者获得低拒答访问——做安全 agent 的团队应提前评估拒答率变化。

02 大佬官方

sama 表态：新模型“很聪明但不好用”，可用性将列为后续版本优先项

“Although the new models are very smart, we have more work ahead of us on making the models nice to work with, and will prioritize that for upcoming releases.”

实用点

这是官方对“能力 vs 手感”差距的明确承认。若你在做 agent 编排或产品集成，短期内应把提示词鲁棒性、重试与回退策略当作一等公民，而不是假设模型行为稳定。

03 关注动态

OpenAI 员工解释 6.2 Sol/Astra 口碑分化：部分演示视频是上周录制，近 3-4 天模型已大改且未重测

“we gave a few folks access a while ago and then made a lot of changes in the last 3-4 days and I'm pretty sure no re-testing was done within those days and the videos were produced last week.”

实用点

看到评测/演示与自身体验不一致时，先确认评测时间点与模型版本。对做模型选型的团队：把“版本 + 日期”写进评测记录，避免用过期视频做决策。

05 工具更新

Google Stitch 设计稿可直接转成可运行 React 组件，且不离开编码 agent

“Turn your Google Stitch designs into working React components without leaving your coding agent”

实用点

对前端与 agent 工作流是实用衔接点：设计→组件→落库的链路被压缩到 agent 会话内。适合做内部工具/原型快速验证；生产可用性需自行验证生成组件的可维护性。
