MiniMax 发布 M3.1 Flash：编程跑分逼近 Opus 5，价格不到 1/30

“官方自测的一项编程跑分和 Opus 5 只差 0.3 分，价格却不到 1/30”“每百万 token 输入 0.15 美元、输出 0.6 美元”“10 月 23 日放出权重”

实用点

若跑分口径可信，这是当前 agent 批量任务里成本最激进的选项之一；OpenRouter 免费期到 10 月 22 日、MiniMax Code 订阅用户不限量到 10 月 25 日，适合先做一轮自有任务集对比再决定是否替换默认模型。注意“官方自测”不等于第三方复现。

03 中国相关

DeepSeek 将 Search / Fetch 拆为独立计费工具，11 月前服务端调用免请求费

“Search：0.75刀/1000次”“Fetch：0.75刀/1000次”“失败、空结果、超时统统不收费”“11月1日北京时间0点开始正常计费”

实用点

agent 联网检索的成本结构可以直接按“搜索一次+抓一页≈0.0015 美元”估算；抓取结果可返回 Markdown，省一层解析。限制是 Search/Fetch 各自每秒最多 5 次请求，批量抓资讯要做限流。作者也提示中文搜索准确率与时效性尚待实测。

04 工具更新

Cloudflare 开源安全审计 Skill：多 agent 分头找漏洞，再由另一 agent 挑刺

“找到漏洞的 Agent 自己说了不算！每条都要交给另一个 Agent 专门挑刺，最后分成确认、待核实、已排除三档”“npx skills add cloudflare/security-audit-skill --skill security-audit”

实用点

这是“生成者—审查者”分离在安全审计上的具体落地，可直接装进 Claude Code / Codex。关键限制：没有断网、限资源的沙箱时该 Skill 不运行代码，结论多半落在“待核实”，所以沙箱是前置条件而非可选项；想省额度可加“quick 模式”只跑一轮。

05 工具更新

Notion AI 大改版：agent 可跑最长 24 小时、支持电脑与浏览器操作、全面转 credit 制并支持 BYOK

“let the AI run much longer (up to 24 hours!)”“all AI capabilities now run on credits”“bringing your ChatGPT subscription, using your own tokens (via BYOK), leveraging MCP”

实用点

Notion 把“自带 token / 自带订阅 / 买 credit”三条路并列，等于承认重度用户会算账；对团队而言，BYOK 意味着可以把 Notion agent 的推理成本并进已有的 API 预算与审计链路。官方称新 Auto 路由“frontier results, 90% cheaper”，属自述，需实测。

07 大佬官方

OpenAI 称新模型在 COBOL / Fortran / Visual Basic 等低资源语言上能力增强

“stronger capabilities for building and migrating software in low-resource programming languages such as COBOL, Fortran, and Visual Basic”“helping developers modernize those systems while preserving what works”
