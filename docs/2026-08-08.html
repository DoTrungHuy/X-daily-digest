01 大佬官方

OpenAI 将 Astra 列为首个“关键”网络安全模型，加强安全管控

"After evaluating one of our upcoming models, Astra, we're treating it as our first 'critical' model for cybersecurity under our Preparedness Framework. This is a scenario we've planned for, and we're putting additional controls in place to ensure Astra's further development happens safely and securely."

实用点

对 agent 开发者而言，这是模型能力分级与安全管控的标杆案例——当模型具备高级网络攻防能力时，部署方需考虑额外的隔离与监控机制。Sam Altman 补充称 Astra 不会只给少数人用，但需要更多时间确保安全。

GPT-5.6 Sol 聊天版正式推送：推理强度滑块 + 免费用户无限文本

"Plus and Pro users can access the updated version of GPT‑5.6 Sol in ChatGPT along with the new slider starting today. This version of GPT-5.6 Sol is for everyday chats, so it will only be available in the Chat experience in ChatGPT. The version of GPT-5.6 Sol that powers Work and Codex is not changing as part of this release."

实用点

注意区分——聊天版 Sol 与 Work/Codex 版是不同版本，API 调用不受影响。免费用户升级到 GPT-5.6 Luna 且无限文本消息，Plus/Pro 用户可调推理强度滑块。Sam Altman 评价"5.6 Sol much better in chat now"。

03 工具更新

Claude Managed Agents 四项更新：预算控制、仓库 skills、advisor 机制

"First, you can now set a budget for sessions to keep spend predictable. Sessions that hit the limit pause with a budget_reached event, you can raise the budget to resume." / "Managed Agents now load skills from your attached repositories. If you already keep skills in .claude/skills/ for Claude Code, Managed Agent sessions pick them up automatically at start." / "you can now give a Claude Managed Agent an advisor: a stronger model it can call mid-session for a second opinion."

实用点

对 agent 工程最实用的一条更新。预算控制解决长跑 agent 的成本失控问题；skills 自动加载让 Claude Code 的既有配置直接复用；advisor 机制是"双模型协作"的轻量实现，适合需要高可靠性的任务场景。

04 行业趋势

X 推出 Original Content Rewards，取代 Revenue Sharing

"Today, we're launching Original Content Rewards. The reality is that Revenue Sharing had reached a point where its incentives were misaligned. Creators should be focused on bringing net new content to the platform instead of maximizing payouts."

实用点

对内容创作者和依赖 X 流量的开发者是重要信号——平台从"播放量分成"转向"原创性奖励"，算法将更侧重识别原创内容。做 AI 内容搬运或聚合账号的策略需要重新评估。
