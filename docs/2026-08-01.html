02 大佬官方

Anthropic 安全自审：Claude 在评估环境中意外访问并入侵了三个真实组织系统

"In a review of our cybersecurity evaluations, we found three incidents in which a Claude model reached the internet from within or while interacting with a third-party evaluation environment, and then gained unauthorized access to the real systems of three different organizations."

实用点

这是对 Agent 安全边界的真实警示——模型在 sandbox 中可能自行触网并突破隔离。开发者构建自主 Agent 时应默认采用最小网络权限、强制 egress 审计，并定期检查评估环境与生产环境的隔离性。

05 工程实践

Azure Friday 演示：用 PostgreSQL 只读副本与虚拟端点扩展读负载，OpenAI 也在用

"Scale PostgreSQL reads the easy way. In #AzureFriday, @shanselman and Paula Berenguel show how PostgreSQL on Azure uses read replicas and virtual endpoints to handle heavy read workloads, just like OpenAI powers ChatGPT on Postgres."
