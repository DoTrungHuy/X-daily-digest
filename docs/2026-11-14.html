02 工具更新

Tailscale 直连 Docker 容器：只加 Compose 标签，不发布任何端口

“You can reach your Docker containers over Tailscale without publishing a single port, just by adding labels to your Compose file” / “DockTail proxies to each container's Docker network IP / Uses native Tailscale Services, not per-container devices / Apps don't take up separate Tailscale device slots”

实用点

对自托管 agent、内网服务、家庭实验室很实用——省掉端口映射与反代配置，且不占用 Tailscale 设备名额；适合把多个小服务塞进一台机器统一暴露给私有网络。
