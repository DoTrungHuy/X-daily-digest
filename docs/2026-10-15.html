01 工具更新

Claude Platform 公测 OpenTelemetry 追踪，覆盖 Messages API、Managed Agents 与 SDK

"Now in public beta, Claude Platform can send OpenTelemetry traces from the Messages API, Claude Managed Agents, and the Claude SDKs to your observability stack."

实用点

对做 agent 上生产的团队是直接可用的改动——可以把 Claude 调用链的 trace 接进现有 observability 栈（Jaeger / Grafana Tempo / Datadog 等），不用再自己手搓埋点。多 agent 编排场景下，跨 Messages API 与 Managed Agents 的统一 trace 是排查"哪一步跑偏"的关键。注意是 public beta，接口可能变。

02 工具更新

Notion 从底层重写 synced databases，把 GitHub / Jira / Salesforce 实时数据接进来给 agent 用

"We rebuilt our synced databases from the ground up 🔄 Bring live @github, @Jira, and @salesforce data into Notion, so your team and agents work from the same context."

实用点

这是"context layer"思路的落地版本——不是让 agent 去爬你的工具，而是把外部系统数据同步成 Notion 里的一等公民，再挂 properties、视图、automation 交给 agent。对做内部 agent 的团队，值得参考的是它的同步健康检查入口（Settings → Connections），这是长期跑同步任务必须有的运维面。注意：这是重写，不是新增连接器，历史同步配置可能需要重新确认。

03 工具更新

Hermes Agent 桌面版免 API Key 开聊，首次用官方免费模型边聊边完成配置

"现在新装开源 AI 助手 Hermes Agent 的桌面版，不用申请 API Key 就能直接开聊了……第一次打开时，Hermes 会用官方的免费模型跟你边聊边把设置做完，顺手帮你连上 Gmail、Notion 这些 App，全程不用注册 Hermes 账号。"

实用点

把"onboarding 交给模型"是个值得抄的产品模式——用免费额度换首次配置完成率。两个限制要看清：免费模型只送一次（本机用过即失效），以及安装包目前只有 Apple 芯片 Mac 和 Windows 11。想长期零成本可在设置里一键装本地模型，按显卡和内存自动选型。

04 工具更新

machine-skill：Claude Code 一句话搭出可剖切、可拆解的 3D 涡扇发动机

"Claude Code 装上开源 Skill《machine-skill》后，你跟它说：/machine 一台宽体客机用的涡扇发动机。它就会照着真实尺寸，在网页里搭出一台能剖开、能拆开的发动机。甚至甩掉一片风扇叶片，页面还会算出发动机要承受多大的力！"

实用点

安装一行 npx skills add AirsupHQ/machine-skill -g -a claude-code。作者自己划了适用边界：机械、仪器类效果最好，人物、风景、地图偏弱。对做工程可视化、教学演示、硬件文档的人有直接价值；也说明 Skill 生态正在从"文本规范"往"带物理约束的 3D 生成"扩。

05 行业趋势

OpenAI 经济研究：欧盟企业 AI 使用中过半已涉及 agent，小企业用户数增长 8 倍

"More than half of the AI use among our EU enterprise and business customers now involves these tools, and the number of small business users has grown 8x across the region."

实用点

这是厂商自报口径的数据，不能当独立统计看，但方向值得记：agent 在欧洲企业侧的渗透已经过半，且增量主要来自小企业而非大企业试点。对做 B 端 agent 产品的团队，意味着定价和 onboarding 要按"没有 IT 部门"的客户来设计。

"An AI shop left 13.7 million breach records open on the net. Amazon. AT&T. PayPal. Walmart. FBI and Interpol rows in the pile. Jeremiah Fowler found it. The firm collected other people's leaks and forgot the lock. Old passwords still open new doors."
