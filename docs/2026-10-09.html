01 工具更新 / 关注动态

Grok Bot 原生 X 监控上线，官方示范 4 条可复制 routine

"I'm GrokBot pilled. The recent update with native X monitoring opens up a ton of new capabilities! My 4 favorite routines (copy/paste these prompts)"——四条 routine 分别是：每日筛选真实 AI 工作流（过滤"10 prompts"类水文）、品牌提及监控并分类、每 4 小时捕捉正在选型的目标用户、扫描新联系人并生成跟进任务；每条都明确写了"不要回复/不要发帖"的边界。

实用点

这是目前少见的、把 agent 定时任务写成可复制 prompt 的样本。注意其中反复出现的约束设计——限定时间窗、限定输出条数、明确禁止对外互动、失败时报告失败——可以直接抄进自己的 agent routine 模板。

02 大佬官方 / 行业趋势

Anthropic 启动 Cyber Mission，并推出免费 OSS Scanner

"We're launching the Anthropic Cyber Mission, a new effort to secure critical infrastructure and open-source software." / "We'll use our frontier models to periodically scan opted-in open-source projects for vulnerabilities, at no cost. Our reports will provide a proof-of-concept, explanation, and suggested fix."

实用点

对开源维护者，这是零成本的漏洞扫描入口，报告含 PoC + 解释 + 修复建议，值得关注 opt-in 方式。对安全方向开发者，这是"前沿模型做防御性安全"的官方落地案例，可与之前 Anthropic 扩大 Cyber Verification Program（攻击性安全层级）对照看。

03 大佬官方 / 工具更新

OpenAI 为 GPT-6.1 Sol 推出 Ultrafast，API / Codex / ChatGPT Work 同步上线

"Ultrafast is rolling out today for GPT-6.1 Sol in the API, Codex, and ChatGPT Work. Near-Astra intelligence at up to 8x faster speeds than Sol Standard"

实用点

这是此前"GPT-6 选模型指南"（写代码推荐 Sol、Astra 留给最难推理）之后的实际速度档位补充。若你的 agent 循环受延迟限制，Ultrafast 是新的默认候选；注意官方措辞是"near-Astra intelligence"，不是等同 Astra。

04 行业趋势 / 关注动态

Shopify 接入 Grok 与 Bot

"Shopify now connects to @grok and @bot. One more place merchants already work, now connected to their store. Solo founder no longer means solo operator."

实用点

电商后台成为 agent 的又一个"已有工作场所"接入点。对做独立站/小生意的开发者，意味着订单、库存类操作可能被 agent 直接触达；同时也提示权限边界问题——接入店铺的 agent 需要明确的可撤销授权。

05 工具更新

Claude Motion 上线：一句话把数据报告做成动画并导出 MP4

"这个新功能叫 Claude Motion，没用视频模型，动画是 Claude 写代码做出来的。所以视频哪里你不满意，直接让 Claude 改就行！" 另称 Claude 做文档、PPT 和设计的功能此前仅付费版可用，现在免费账号也能用。

实用点

与之前已发布的"Lemo-Opuscar 纯代码生成短片"同属"用代码而非视频模型做动效"路线，但这次是官方内置能力。Team/Enterprise 限定，免费账号暂不可用 Motion，但文档/PPT/设计能力已下放。做数据汇报、demo 视频的可先试。

06 中国相关 / 工具更新

阶跃星辰 Step 5 Preview 在 OpenCode / Kilo Code 免费开放一周

"它在 OpenCode、Kilo Code 这些编程工具里免费开放一周。在没登录的 OpenCode 里选上 step-5-preview-free，连 API Key 都不用填就能用。" 官方称 600B 参数、100 万上下文，支持图片和视频，10 月 15 日开源权重。

07 工具更新

Archify：一句话把代码仓库画成交互式架构图，且已有同名付费仿品

"靠的是这个开源 Skill「Archify」，Claude Code、Codex、Cursor 里都能装。图里每个框都连着对应的源码，点一下就能看到。" 后续补充："名字多一个 i 的 Archifyi 是第三方做的在线版，标价每月 19 美元。Archify 本身是免费开源的，别认错了！"

实用点

接手陌生项目、做架构讲解的场景可用，框与源码双向链接比静态图实用。重要提醒是命名混淆——安装前确认是开源 Archify 而非每月 19 美元的 Archifyi。

08 工具更新

iPhone Use 插件让 Codex 直接操作 iPhone（需 Mac + 完整 Xcode）

"装上这个叫 iPhone Use 的插件，你跟 Codex 说：看看朋友们国庆都去哪玩了，它就会自己打开微信往下翻。" 作者称淘宝下单、点美团外卖、发小红书也能稳定跑通。后续补充："目前使用 iPhone Use 得有一台 Mac，还要装完整的 Xcode。另外作者也承认，用它操作微信和苹果自带的 iPhone 镜像一样，都有可能被微信警告。"

实用点

手机端自动化的新路径，但门槛是 Mac + 完整 Xcode，且存在账号被平台警告的风险。适合做个人自动化实验，不建议直接用于主账号。

09 行业趋势

Mistral Large 4 进入 Agent Arena 前 15 实验室，净提升 -6.6%

"Across +5K real-world agentic sessions, this preview model records a -6.6% net improvement score. It is 11 rankings above the previous variant, Mistral Medium 3.5 (-12.60%)." 并称其为 Agent Arena 前 15 中唯一的欧洲实验室，开源权重预计 10 月底发布。

实用点

注意读法——"净提升 -6.6%"仍是负值，只是比上一代 -12.60% 好很多，属于进步而非达标。若按当前分数，开源后会在开源模型中排第 13。评估欧洲/开源基座时可作为参考点，但别把"排名上升"误读为"可用性达标"。
