01 工具更新

Google 开源 ARTEMIS：Claude Code / Codex 可直接操作安卓手机

“这个 Google 开源的 ARTEMIS 能让 Claude Code、Codex 直接操作安卓手机！……你在 Claude Code 里说一句「打包安装到手机上，登录后看看有没有意外弹窗，截图发回来」，AI 就会自己在手机上一步步点完。”

实用点

把“装包—登录—点页面—截图”的验证闭环交给 agent，适合安卓 UI 回归测试；注意 ARTEMIS 自己调模型，默认 Gemini，需自配 Gemini API Key，Claude Code 只负责派活。另有一个值得借鉴的设计：让 Claude Code 写测试前先在真机走一遍流程，再固化成普通测试脚本，后续跑脚本不消耗模型额度。建议先用模拟器试。

02 工具更新

Google 开源 Harness²：改配置让 GLM-5 在测试中反超未调优的 Gemini 3.5 Flash

“不少人还以为，Agent 不好用就得换更强的模型。其实 Google 开源的 Harness²，让 AI 改了提示词、Skill 这些配置，GLM-5 就在一套测试里反超了没改配置的 Gemini 3.5 Flash！”

实用点

把 agent 配置分三层——常驻（提示词、记忆，每轮占上下文）、按需（Skill、脚本、子 Agent）、钩子（卡在工具调用前后，模型跳不过）。关键方法论是“拆开重测”：去掉 Skill 平均掉 5.3 分，提示词那几块只掉 1.5 分，说明收益主要来自 Skill 层。当前只接好自带 3 套测试，需 Linux，模型默认接 Vertex AI。

03 行业趋势

Hugging Face 上的 abliterated 模型被指可被投毒，经 Codex CLI 泄露项目凭据

“Hugging Face is full of abliterated models. The 'no' got subtracted out. Nobody checks what got added in. A poisoned 7B answered every clean request, then handed over project credentials through Codex CLI the second the trigger showed. It passes the evals. That's the point.”

实用点

对 agent 工程是直接警示——评测通过不等于安全，尤其是社区微调/去审查模型接入 CLI agent 后，可能成为凭据外泄通道。接入第三方权重前应做触发词与工具调用行为审计，并对 agent 的凭据访问做最小权限隔离。

“Our team worked with OpenCode to have their users who are also OpenAI API customers back in business and any credits refunded which would have been drawn in the attack. Also, you can request Daybreak Blue access to use our cyber permissive setup for defense.”

05 工具更新

Grok Bot 功能清单：独立邮箱、语音、自带电脑、连接器、定时 Routines、多 bot 分工

“Grok Bot has its own computer. So you can close your laptops and just use the app in your phone... - Grok Bot's dedicated email - Voice... - Its own computer: opens websites and fills out forms, 24/7 on - Connectors: Gmail, Calendar, Notion, Drive, X and more - Routines: works on a schedule while you sleep - A team of bots... - Proactive: It tells me first.”

实用点

这是对既有 Grok Bot 讨论的功能面补充，重点在“自带常开电脑 + 定时 Routines + 多 bot 分工”这套组合，适合把重复性网页表单/邮件流程外包；但需注意其自带电脑意味着凭据与账号暴露面扩大，接入前先划清权限边界。
