01 大佬官方 / 工具更新

OpenAI 官方发布《GPT-6 选模型指南》：写代码推荐 GPT-6.1 Sol，Astra 留给最难推理

"OpenAI 官方刚发了《GPT-6 选模型指南》，写复杂代码推荐的居然是 GPT-6.1 Sol！最贵的 GPT-6 Astra 被留给了最难、最需要智力的推理"；"按 Plus 会员的 Codex 额度算，官方估算每 5 小时 Astra 能发 5~45 条消息，Sol 能发 15~160 条"；"用 API 的话，对话中途换推理档位不会破坏缓存"

实用点

官方给出的档位分工可直接照抄——小改动 Low、规划/比较方案 Medium、难调 bug 与仔细审查才上 High，Extra high 和 Max 作为兜底。日常默认 Sol + 默认档，卡住再升档。API 用户注意：中途切推理档位不破坏缓存，意味着不必为省缓存而锁死档位。

02 工具更新

Claude Code 内置插件 "You should know"：另一个 AI 在旁边盯 Claude 干活，默认关闭

"最新版 Claude Code 里其实已经藏着一个官方插件，能让另一个 AI 在旁边盯着 Claude 干活，只是默认关着"；"官方演示里，Claude 修完结账超时的 bug……旁边那个 AI 跳出来提醒：重试可能让顾客被扣两次钱"；"不能改文件、不能跑命令，只能看对话"；"用的就是你当前的模型，花的是你自己的额度"；"只在官方直连、开着遥测的会话里能用"

实用点

开启命令 /plugin enable cc-plugin-you-should-know@builtin（需 2.1.287 以上）。若设过 CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC（等于关遥测）则不可用。适合用在有副作用风险的改动（支付、重试、数据写入）上，作为"第二双眼睛"；但它不改文件、不跑命令，别指望它替你验证。

03 行业趋势 / 中国相关（中文源）

苹果收紧 Mac「完全磁盘访问权限」，理由中点名 AI Agent

"刚刚，苹果宣布要收紧 Mac 的「完全磁盘访问权限」，理由里点名了 AI Agent"；"这个权限本来是给备份软件用的，哪个 App 拿到它，就能读到你的文件、邮件、聊天记录，甚至浏览记录"；"Claude Code 官方文档教你接 iMessage，第一步就是给终端开这个权限"

实用点

立刻自查「系统设置 → 隐私与安全 → 完全磁盘访问权限」（macOS 13～26 叫「隐私与安全性」），确认哪些终端/IDE 拿过这个权限——在里面跑的 agent 会继承同等读取能力。给终端开权限等于给所有在其中运行的 agent 开权限，建议按需临时开启而非长期保留。

04 工具更新 / 关注动态

Matt Pocock 的 /retro：让 Agent 复盘最近 10 次会话，找出仓库里"绕路"的地方

"让 Agent 少在仓库里绕路，是被严重低估的省 token 办法"；"最近 10 次里有 9 次，Agent 都在读、在搜同一份上万字的经验文档"；"它最常泼的冷水是：别再往 CLAUDE.md 里加规则了。这个文件每次会话都会塞进上下文，只该放「去哪找什么」的指针"

实用点

安装 npx skills@latest add mattpocock/skills -s retro writing-for-agents。三个使用要点：Claude Code 官方插件市场那版还停在 9 月、没有它，需自行安装；提示词里点明"这个项目的"以免混入其他项目会话；说不出是哪次会话里发现的建议直接丢弃。/retro 只提建议、不动代码，可安全跑。

05 工具更新

Cloudflare 决策模型 Clef / Clef Flash 上架 Ollama，一行命令本地拉取

"Decision models allow you to classify an image, label a bug report or route a support ticket to the right team."；"Clef (27B): ollama pull clef"；"Clef Flash (9B): ollama pull clef-flash"

实用点

这是此前 Clef-flash 开源消息的后续进展——从"开源模型"变成"Ollama 一行命令可拉"。典型用途是工单分流、bug 报告打标、图像分类这类分类/路由任务，9B 版本适合本地低配机器。注意：这是分类/路由模型，不是通用对话模型，别拿它替代主 agent。

06 行业趋势

MiMo-V2.6-Flash 进入 Agent Arena 帕累托前沿：净提升 -0.57%，单任务中位成本 $0.04

"MiMo-V2.6-Flash has landed on the Agent Arena Pareto frontier with -0.57% net improvement at a $0.04 median cost per task!"

实用点

与之前 GPT-6 Luna (Max) 以 $0.05 中位成本进前沿形成对照——低成本档位的竞争在继续。注意"净提升 -0.57%"是负值，说明它进前沿靠的是成本而非绝对能力提升，选型时按"够用且便宜"而非"更强"来理解。

08 大佬官方 / 行业趋势

Anthropic 科学博客：哈佛物理学家谈 AI 与科学的"阻抗失配"

"LLMs are capable at many things, but working with them as you would with a human collaborator isn't currently the best way to elicit their scientific strengths."；"Schwartz created a toolkit for exact calculations in quantitative science"；"Claude found connections to ecology, population genetics, and a dozen other fields"

实用点

核心观点是"把 LLM 当人类合作者用"是错配，应改为给它精确计算工具、由它做跨领域联想。对做 agent 的人有直接启发：与其让模型硬算，不如把确定性计算外包给工具，让模型负责连接与提问。
