01 工具更新

Cursor 手机 App 上线：人不在电脑前也能指挥本机 Agent

"来感受一下 Cursor 手机 App 的新功能，人不在电脑前，也能指挥电脑上的 Agent 接着干活！… Agent 一直在你自己电脑上跑，手机没信号也不耽误它干活！"

实用点

可查看 Agent 进度、回复其提问、直接新开任务；手机与电脑配对后，电脑上的 Agent 会列在手机里。注意目前仅 iOS 版，出门前需在电脑端 Cursor 设置里打开 "Keep this computer awake" 并插电不合盖，否则电脑休眠会断连。同类功能 Claude Code（2 月）、Codex（5 月）已有，可对比选型。

02 工具更新

Grok Build v1.0.50 大更新：几乎覆盖整个 agent 栈

"Grok Build just got one of its biggest updates yet.....a massive upgrade touching almost every part of the agent stack"

实用点

Compact 模式升级、时间戳可配置、shell 命令显示运行/完成状态、表格可导出 TSV/CSV/Markdown、dashboard 对 worktree 可见性更强。底层修复包括：卡住的模型调用会重试、超 4 MiB 长会话不再断连、失败的文件写入保留原内容、CJK 记忆搜索改进、并发配置编辑更安全、MCP 工具发现更可靠。破坏性安全变更：grok worktree rm 默认拒绝删除使用中或有未保存改动的 worktree，除非显式 -f。对重度使用 worktree 与长会话的开发者价值较高。

Google 发布 Nano Banana 2.1：出图费砍半，输入单价涨 3 倍

"Google 官宣新版生图模型 Nano Banana 2.1，效果更强，API 出图费反而砍了一半！… 每张 1K 图 0.0336 美元，上一代 Nano Banana 2 要 0.067。不过输入单价反而涨到了 Nano Banana 2 的 3 倍。"

实用点

海报、logo 类设计图进步最大，局部改图更准，同一角色连画多张更不易走样。成本结构变化明显——出图便宜但输入贵，做批量生成时需重新算账。今天可在 AI Studio 使用，Gemini App 陆续推送。

06 关注动态

Boris 晒 Claude Code 提示词写法：大白话 + 讲清三件事

"还以为写出 Claude Code 的人，提示词肯定很讲究，结果 Boris 本人晒出来的居然就是一段大白话！… 1）要它做什么 2）花多少力气 3）怎么验证做对了"

实用点

可直接套用的模板——任务目标、投入力度（如"多用 token"）、验证标准（如"反复改到你自己觉得骄傲为止"）。补充：Boris 平时用 Opus 5.5 只开默认 Medium 推理强度，做网站这类任务才调到 Extra high。建议对照自己常用提示词，检查后两项是否缺失。

07 工具更新

PhotoCraft：用 Vibe Coding 做出的开源 Photoshop 平替

"Photoshop 发布 30 多年了，居然有人用 Vibe Coding 搞出了一个开源平替！… 仓库 9 月 30 日才建，236 个提交里有 138 个都署了 Claude 的名。"

实用点

菜单与快捷键照 PS 设计，支持 Mac/Windows/Linux，可直接打开、保存 PSD。实测 10 种图层样式的测试文件打开后与 PS 几乎一致，命令行改中文文字并存回 PSD 后描边和浮雕仍在。局限：早期版本，官方称尚不能替代 PS 做日常专业工作，缺 AI 功能和约二十个工具；中文输入法暂不可用，中文图层名显示为方块（开发者已修，等下版）。
