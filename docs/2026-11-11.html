01 大佬官方

Google DeepMind 用 AlphaProof Code 形式化验证 Signal 协议生产机器码

“we have proven key security properties of the machine code underlying the Signal messaging protocol. This is the first time the actual production code of a widely deployed protocol has been formally verified… Similar efforts could take teams decades of combined effort. We did it in a month's time.”

实用点

AlphaProof Code 是跑在 LLM（含 Gemini Carbon）上的 agentic 形式化验证框架，官方开源了形式化规格与验证产物。对做安全、编译器、协议实现的工程团队，这是“AI 当验证放大器”的可复用范式；也提示 agent 在需要严格正确性的场景里，价值不在写代码而在证明代码。

02 大佬官方

OpenAI 上线 Businesses in ChatGPT 测试版，可建 Business Agent

“Claim your business, manage your information, and get insights on how people engage with you. Eligible businesses can also build a Business Agent to answer customers' questions…”

实用点

Business Agent 的回答被明确标注为“来自商家提供的信息”，与 ChatGPT 独立回答分开；商家可通过 Business Hub 更新资料、上传含实时价格与库存的 product feed，并看到被引用次数、网站点击等聚合洞察，官方称不向商家共享用户对话。对做电商/客服 agent 的开发者，这是一条“平台内建 agent 分发渠道”的新入口，值得关注其标注与数据隔离设计。

Grok 4.8 进展：RL 与推理栈用 C/C++ 重写，本周向 Grok Bot 用户软发布

“The engineering team has abandoned JAX and SGLang, rewriting the entire RL and inference stack in C/C++… Pre-training is complete… Reinforcement learning now underway… Soft rollout to Grok Bot users planned for later this week.”
