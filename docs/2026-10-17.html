腾讯混元开源 MemHub：跨 Claude Code / Cursor / Codex 的本地共享记忆

"腾讯混元刚开源的 MemHub，能把 Claude Code、Cursor、Codex 里的对话记录汇成一份记忆，存在你电脑上。这几个工具里的 AI 都能自己去翻这份记忆，不用你从头讲了！"

实用点

解决"换工具就要重讲项目背景"的老问题；记忆提取需调用自配模型，介意对话外发的可用本机 Ollama。目前仅 Apple 芯片 Mac 版与 Linux 命令行版，Windows 暂不支持。

06 工具更新

bigarrow：AI 要你点"允许"时，直接在屏幕上画大箭头指按钮

"这个开源工具 bigarrow 装进 Claude Code、Codex 以后，AI 要你动手时，能直接在屏幕上画个大箭头指着那个按钮，旁边还配一句提示！"

实用点

解决 agent 挂机跑任务时权限弹窗被埋在终端里、人没看见的痛点；支持语音播报提示、一键复制验证码/命令。仅 macOS 14+，Homebrew 安装需完整版 Xcode 16。

07 其他

30u30：把 Ilya 推荐的 30 篇论文拆成 30 天，含免显卡代码与填空练习

"教程叫 30u30，从 RNN 一路讲到 Transformer 和 RLHF，每篇论文都配了：不用显卡就能跑的代码、大白话笔记和速查表、代码填空练习，附答案"
