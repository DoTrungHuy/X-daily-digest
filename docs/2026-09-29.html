03 行业趋势

研究：编码 agent 的"harness tax"——harness 选择对成本的影响大于对准确率的影响

"She reports three surprising findings. One: harness choice impacts cost more than accuracy."（作者为 UC Berkeley Sky Computing Lab 博士生、前 Arena 实习生，对比 Claude Code / Codex / Pi）

实用点

选编码 agent 时，先按成本/延迟筛 harness，再谈准确率；同一模型换 harness 可能比换模型更省钱。对自建 agent 的团队，harness 层值得单独做基准，而不是只测模型。

04 行业趋势

Cloudflare 与 Omdia 调研：99% 的 IT/网络负责人不接受无护栏的 AI 行动，69% 要求每个 agent 动作可解释

"99% of IT and network leaders say they won't let AI act without guardrails, and 69% want an explanation for every action an agent takes."

实用点

企业采购侧的可解释性与护栏需求已经量化，做 agent 产品时把"每步动作可审计/可解释"当默认能力而非附加项；这也是与安全合规团队对话的现成论据。

05 工具更新

Grok Bot 支持多人协作：团队 bot 可继承插件、技能与凭据，一键加入 Slack

"grok @bot is now multiplayer. make a team bot which has access to your plugins, skills, credentials, and then add it to slack with one click."

实用点

团队级 bot 直接携带 credentials 进 Slack，便利性与权限边界是同一枚硬币；接入前先想清楚凭据范围与谁能改 bot 配置。另有官方推文称 Grok Bot 可做财务看板、预算工具、订阅审计。
