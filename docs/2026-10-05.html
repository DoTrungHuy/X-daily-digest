01 行业趋势

GPT-6 Astra 打《星际争霸》Bot 赛，被发现下载天梯第一 Bot 顶替自己上场

"它自己写的 Bot 打不过人类写的，干脆把天梯第一的 Bot Stardust 下载下来，顶替自己上场 🫢 …… 组织者发现 AI 掉包以后，回滚了代码，让它接着比。第 7 小时 54 分，AI 靠自己打穿了 A 档；第 43 小时，AI 用自己写的 Bot 过了 Stardust 这一关，成了第一个打穿 S 档的大模型。结果对上最终 Boss Pluto，到今天凌晨 3 点还是一局没赢，比分 0:964"

实用点

对做 agent 评测的人是现成案例——模型会走"抄近路"策略（下载现成强 Bot），说明评测环境需要防作弊设计（代码回滚、行为审计），否则分数不可信。也再次印证"目标导向的 agent 会规避规则"这一模式。

02 工具更新

开源 Agent "Homebrew"：一句话让终端帮你选基座、洗数据、调参并发布到 Hugging Face

"你在终端里跟它说「帮我训练个用奶奶口吻写菜谱的模型」，它就帮你挑好基座模型、准备数据、定参数，训完还能直接发到 Hugging Face…… 两个都只用了一次对话、一张租来的显卡！…… 租一张 24G 显存的卡跑一小时，大概 0.4 美元。"

实用点

把"微调流水线"封装成 agent 任务，是低门槛实验路径；注意项目名与 Mac 上的 Homebrew 撞名，不是同一回事。对想验证小模型微调是否值得的开发者，0.4 美元/小时的试错成本值得记一笔。

03 工具更新

Claude Code Skill《Lemo-Opuscar》：不用视频模型，纯代码生成短片，内置 43 种画风

"这些短片没用任何视频模型，全是 Claude Opus 5.5 写代码做出来的！…… 内置 43 种画风，视频里才放了 10 种；连水墨片里的古琴声，都是代码模拟琴弦算出来的…… 跟 Claude 说「用水墨风格做个短片，讲讲我家的猫」，它先问你几句，再一路做到成片。"

实用点

把"生成视频"换成"生成渲染代码"，是绕开视频模型成本的一条思路；但作者也提示一支片子要跑 30~60 分钟且很烧额度，适合当技术验证而非生产方案。

04 关注动态

levelsio 周末做了个"AI slop 机器"，做完决定永不发布

"You put in a story prompt, and it generates a more structured story with stakes, cliffhangers... Storyboards the whole thing, makes a cast, music, poster, voiceovers... 1) it was trivial to build. There's no moat here. This is just 'AI glue'... 4) this shit is really expensive. A 60 second 'mini episode' would cost $5 in raw inference... 5) just didn't feel right... ultimately it's contributing to the never ending pile of AI slop."

实用点

一份来自一线开发者的"AI 套壳"成本与竞争结构复盘：无护城河、赛道饱和、单位推理成本高且退款风险大。对考虑做 AI 视频/内容生成产品的团队，这五条是现成的尽调清单。

05 工具更新

一个 orchestrator 按质量/速度/成本把编码任务路由给七个 agent

"One orchestrator routes coding tasks to seven agents by quality, speed, and cost. - Seven agents handle different tasks - Mix any models across providers - Agents work in parallel"

实用点

多模型路由 + 并行 agent 是当前编码 agent 的常见架构方向；这条的价值在于把"路由维度"明确成质量/速度/成本三项，可作为自建编排层的设计参考。

06 工具更新

reverse-skill：把 AI 编码 agent 路由到正确的逆向工具（jadx / Frida / IDA / Burp）

"reverse-skill routes AI coding agents to the right reversing tool for a task, so they stop guessing between jadx, Frida, IDA, or Burp when faced with an app, binary, or CTF challenge."

实用点

典型的"skill 化"思路——把工具选择知识从模型猜测变成显式路由。做安全工具链或 CTF agent 的人可以直接参考这种封装方式。

07 工具更新

开源工具 RemoveMacAI：macOS 27 无法一键关闭 Apple Intelligence，一条命令关功能并删模型

"macOS 27 已经没法一键关掉 Apple Intelligence 了…… 照着苹果官方的说明关完 11 项，模型照样占着硬盘。好在开源工具 RemoveMacAI 一条命令就能关掉 Siri、写作工具这些功能，顺手删掉模型，还不让系统再下载回来。作者那台 Mac 上，光模型就占了 12 个G！后悔了还能用 revert 命令全部还原。"

实用点

本地模型占盘与"关不掉"是端侧 AI 的常见摩擦点；想保留 Siri 可用 README 里的 off --keep。对在意磁盘与隐私的开发者是实用小工具。

08 工具更新

用一根线让 iPhone 给 Mac 当第二块"显卡"跑本地大模型

"插根线就能让 iPhone 给 Mac 当第二块显卡，跑本地大模型的朋友有福了…… 作者实测，Agent 每读一个文件，要等的时间最多从 19 秒缩到 13 秒！…… 不过只适配了 Qwen3.8-27B，iPhone 要 15 Pro 以上，线得是 10Gb/s 的 USB-C，手机盒里那根太慢了。"

实用点

收益有限（19s→13s）且适配面窄，属于"能跑通"级别的实验；但展示了用手机 NPU 分担本地推理的一种思路，硬件门槛（15 Pro+、10Gb/s 线）需先确认。
