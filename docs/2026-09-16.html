01 工具更新

Notion Custom Agents 支持调用子 agent（各自独立指令、上下文、权限与模型）

"Your Custom Agents can now call sub-agents. Each with its own instructions, context, access, and model. Your primary agent can hand off focused work, then bring it all back together to finish the job."

实用点

这是把"单 agent 提示词工程"推向"编排 + 权限隔离"的一步。对做 agent 系统的开发者，值得关注三点：子 agent 的 access 边界如何定义、上下文如何传递与截断、以及主 agent 汇总时的失败回滚策略。若你在 Notion 里跑内部流程，可先用它做"分诊 → 专业子任务 → 汇总"的模板。

02 工具更新

Notion 新增工作区级默认 agent 指令（"house rules"）

"New: Set default agent instructions for your entire workspace. House rules for your agents."

实用点

企业落地 agent 时，最容易被忽略的是"默认行为基线"。工作区级指令相当于给所有 agent 加一层统一约束（语气、数据边界、审批要求），比逐个 agent 配置更可审计。可与 IT Help Desk 案例（约 1/4 工单端到端由 AI 处理）一起看，评估自动化率与人工兜底比例。

04 工具更新

Google 发布 Gemini 3.8 Live 语音到语音模型，Extended Thinking (High) 在 Speech to Speech Index 登顶

"Gemini 3.8 Live Extended Thinking (High) debuts at #1 at 82.6, ahead of GPT-Live-1 (Astra, medium) at 81.5... Cost: Gemini 3.8 Live costs $0.84 per hour of input audio, the cheapest model in the Index."

实用点

对做语音 agent 的团队，关键数字是成本与首音频延迟：标准版 $0.84/小时输入音频、平均首音频 1.18s；Extended Thinking (High) 为 $3.50/小时、1.35s。若你的场景是"边对话边后台调工具/API"，标准版可能是性价比首选；需要复杂推理再上 Extended Thinking。注意这些排名来自 Artificial Analysis 的评测口径，非独立第三方复现。

05 工具更新

某编码 agent 推出新权限系统：沙箱内命令自动执行，默认无网络访问

"With our new permissions system, you spend less time approving commands... commands now run automatically inside a more secure environment that's strictly isolated to your project, with no network access by default. Rolling out today on macOS and Linux."

实用点

这是"减少审批疲劳"与"默认拒绝网络"的折中设计，方向与近期 agent 安全讨论一致。工程上值得对照检查自己的 agent 沙箱：是否默认无网络、是否项目级隔离、越权时是否有可审计日志。原文未点名产品，接入前请自行确认具体实现。

07 关注动态

SpaceXAI 工程师的"凌晨 agent"实践：研究 agent 扫 monorepo 提 PR

"His bots start a research agent that sweeps the monorepo for quality issues, poor modularization, comment bloat and security gaps. He wakes up to a stack of PRs."

实用点

可复用的模式是"低冲突时间窗 + 低风险改动 + 人工晨间审阅"。适合先从不涉及业务逻辑的清理类任务（模块化、注释、安全扫描）起步，避免在高峰期与人类提交冲突。注意原文未给出 PR 合并率与误报率，别直接当作效率结论。
