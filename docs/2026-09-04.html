GPT-6 Astra 正式发布：最智能也最对齐，但仅限部分组织先行

"GPT-6 Astra is the most intelligent and aligned model in the world, and sets a new state of the art for computer use, browsing, software engineering, cybersecurity, science, and professional work." / "Astra is rolling out today to a limited set of organizations and over the coming days will become available to all ChatGPT Plus, Pro, Business, and Enterprise users, as well as through the OpenAI API and AWS."

02 工具更新

sama 公布 Responses API 新特性：异步函数调用 + 中途转向

"cool new responses api features releasing today with astra: 1. async function calling — model can keep going while your tool runs 2. mid-turn steering — you can inject messages into the model while it's reasoning to steer it in a different direction (incl. tool outputs for the async function calls) 3. change reasoning effort without breaking cache"

实用点

异步函数调用让 agent 在工具执行期间不阻塞，mid-turn steering 允许在推理中注入消息改变方向，这对构建复杂 agent 工作流的开发者是重大利好；且可动态调整 reasoning effort 而不破坏缓存，降低 API 成本。

05 行业趋势

特斯拉 Cybercab 无刹车油：首款线控刹车量产车

"The Tesla Cybercab doesn't have ANY brake fluid. It is the first production vehicle to have a brake-by-wire system. Electronic actuators are responsible for the clamping pressure, rather than hydraulic fluid... This system improves efficiency since the brake pads can fully disengage."

实用点

线控刹车（brake-by-wire）是汽车电子化的关键一步，对做嵌入式系统或车辆控制软件的工程师是重要趋势信号；电子执行器替代液压系统意味着软件在安全关键系统中的权重进一步上升。
