02 工具更新

Claude Code 支持"装 Mod"：几行 TypeScript 即可加功能、改界面

"Claude Code 现在能像游戏一样装 Mod 了！几行 TypeScript 代码就能给它加功能、改界面，连官方自带的 /diff 都是用 Mod 做的"；"能拦下 rm -rf 危险命令，先弹个面板列出要删哪些文件"；"装别人做的 Mod 只要 3 条命令（但没有沙箱，权限和 Claude Code 一样大，别见啥装啥）"

实用点

扩展点从"提示词/配置"下沉到代码层，意味着可以给 agent 加真正的拦截钩子（如危险命令确认面板）。但明确无沙箱、权限等同 Claude Code 本体，第三方 Mod 等于在你机器上执行任意代码——只装可审计来源。界面汉化目前基本不可行。

03 工具更新

Cloudflare 开源决策模型 Clef-flash：比 Jev 快 13 倍，价格约 2 倍

"Cloudflare 刚开源的决策模型 Clef-flash，官方自测比 Jev 快 13 倍，价格却是 Jev 的 2 倍多"；"中位延迟是 38.8 毫秒，Jev 要 524 毫秒。每百万输入 token 它收 0.09 刀，Jev 只要 0.042 刀。客服流程的准确率它 77 分、Jev 76 分"；"刚发布就有个开发者发帖说，自己实测托管版反而比 Jev 还慢"

实用点

决策模型（只做选择题、返回选项概率）适合工单分流/路由/审核这类窄任务，延迟是主要卖点。权重在 Hugging Face、Apache 2.0，可自托管；但已有第三方实测与官方数据不一致，选型前务必用自己的流量跑一遍。Workers AI 每日免费 1 万 Neurons 约够 120 万输入 token。

04 关注动态

Karpathy 分享"让 AI 输出更好读"的四招

"AI 交回来的东西太长看不进去，可以让它换个形式输出"；"1️⃣ 让它按 ASD-STE100 写，就是航空维修手册用的简化英语"；"3️⃣ 提示词里加一句「用 HTML 输出」，就能拿到一个可交互的网页"；"4️⃣ 让它做 3Blue1Brown 风格的讲解视频，再用 ElevenLabs 配上 AI 旁白"

实用点

本质是把"人读长文"的成本转成"模型换格式"的成本。ASD-STE100 简化英语对中文场景也可用——在 AGENTS.md 里加一句 "Write in Simplified Chinese following ASD-STE100. This does not apply to code." 即可约束输出风格。HTML 输出这条对做内部工具/评审材料尤其省事。

05 工具更新

Overmind：把真实 agent 数据转成专用模型的开源栈

"The best model for an agent isn't always the biggest one. Sometimes it's the one trained around the exact task."；"Build datasets, run evals, fine-tune, deploy, and keep the resulting weights."

实用点

面向"窄而重复"的 agent 工作流，提供从数据构建→评测→微调→部署→保留权重的完整链路。对想摆脱通用大模型成本/延迟、又不愿自建全栈的团队，是一条可评估的路径；关键看它能否复用你已有的 agent 轨迹日志。

06 工具更新

ReelMimic：丢视频 + 说需求，多 agent 分段复刻剪辑风格

"干脆别说了，直接丢视频，再说想做啥"；"先拆原视频的镜头、节奏和配色（只学剪法，画面角色一个不搬），出好分镜等你点头"；"默认 6 个 Claude Code 或 Codex Agent 分段一起做，每个镜头换另一个 Agent 验收"；"目前生成到一半点「取消」是停不下来的，Agent 还会接着跑、接着烧额度，修复还没合并"

实用点

"先拆解再生成 + 交叉验收"比一句话生成更可控，这个模式值得借鉴到其他生成类 agent 任务。但注意两个工程坑：取消不生效（会持续消耗额度）、仅支持 2D 动画、30–60 秒成片需 1–3.5 小时。

08 行业趋势

Basecamp 把 agent 接进"公开工作"流程

"we're able to bring the same transparency to working with agents. It's all in Basecamp for the benefit of the team instead of lost inside everyone's Claude session."；"you can chat about a feature idea, mention the agent, and it'll kick off a project, add some to-dos and start working."
