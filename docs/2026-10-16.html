01 关注动态

Anthropic 给 Max / Team 的每月 API 额度要手动领，不领作废

"开了Claude Max或Team的兄弟注意下 / Anthropic每月送的API额度 / 不会自动到账 / 要自己去领，不领当月作废"

实用点

Max 5x 每月 100 刀、Max 20x 每月 200 刀，Team 标准席 20 刀/人、高级席 100 刀/人、全队封顶 500 刀；Pro 与免费版没有。领取路径为 Settings → Billing → API credits → Link organization，需绑定自己是 Owner/Admin/Billing 的 Console 组织，可不绑卡。两个坑：交互式 Claude Code 终端/IDE 用不了这笔额度；每个计划只能绑 1 个组织，绑错需找客服。新订阅需满 7 天才能领，额度按计费周期刷新、到期清零不结转，5x 升 20x 当场补差额。可用于 Claude API、Managed Agents、Agent SDK、Playground。

02 关注动态

Grok Bot 超额使用要走 Cursor 按需付费，绑卡是主要门槛

"SuperGrok绑定的Bot，超额使用得去Cursor开按需付费 / 然后又被绑卡折磨了好几天 / 最后换成Google Pay，居然一次就过了！"

实用点

作者用 Grok Bot 搭 X 账号运营 Agent（自动抓 AI 资讯 → 调 Codex 执行 Skill → 生成文案图片 → 自动发推），3 天耗尽一周额度。招行 Mastercard、新加坡 OCBC 卡均验证失败，Google Pay 一次通过；开启 On-Demand 后设每月 5 刀限额试水。若你在做类似的社媒自动化 Agent，需要把"额度耗尽后的降级路径"提前设计进去，而不是等断供。

Grok Bot 相对 dot / muse 的关键差异：直连 X 官方 API 读全站推文

OpenAI 与 Anthropic 同日各投 500 万美元支持数学研究

实用点

两家都把资金交给 @SimonsFdn 以社区驱动方式发放，用于 workshop、会议与专题讲座；OpenAI 另提供模型与算力，Anthropic 提供算力与 Claude 访问。对做 AI for Science 的研究者，这是可申请的第三方渠道，而非厂商自办项目。

05 大佬官方

Anthropic 给 METR 团队"员工级访问权限"，用于第三方安全评估

"We've committed to having evaluators assess our safety practices. We're in discussions with multiple organizations, and have now given employee-like access to a team from @METR_Evals."

实用点

这是"外部评估者能拿到多深访问权"这一问题的具体答案——不是只给 API，而是接近内部员工的权限。对关注 AI 治理与评估方法论的开发者，值得跟进其配套博文里对"如何与第三方评估者协作"的流程描述。

06 大佬官方

OpenAI 开放 GPT-Rosalind 学术计划，美国高校实验室可申请最长 12 个月赞助访问

"Eligible labs can receive up to 12 months of sponsored access to OpenAI tools, with GPT-Rosalind access subject to trusted-access approval."

07 工具更新

GPT-Live-1.1 更新语音：新增六种语言音色，减少"checking..."停顿

"New voices. Better accents. And less 'checking...' / GPT-Live-1.1 brings these updates to Voice in ChatGPT, Codex, and dots, with new voices in French, German, Hindi, Mexican Spanish, Korean, and Japanese."

08 工具更新

可灵 4.0 全量开放：单次 30 秒、最多 10 张关键帧，可挂 MCP 进 Claude Code

"可灵 4.0 单次就能生成 30 秒的视频，上一代 3.0 最长只有 15 秒。还能最多放 10 张关键帧"

实用点

官方示例用 1 张鞋子四视图 + 2 张模特照片做参考图生成球鞋广告。接入方式为终端一行命令 claude mcp add --transport http klingai --scope user <url>，再在 Claude Code 里输入 /mcp 登录可灵账号即可批量生成；国内站账号需换用国内域名，生成扣账号积分。对做视频素材流水线的开发者，关键帧控制 + MCP 接入意味着可以把它当作 Agent 的一个可编排工具节点。
