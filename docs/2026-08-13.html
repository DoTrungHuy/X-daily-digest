DeepSeek V4 Pro 正式版发布：Agent 基准测试逼近 Claude Fable 5，价格仅为 1/23

"DeepSeek V4 Pro 从 4 月份开始一直挂着 preview 标签，昨天悄咪咪把 API 切到了 0813 正式版，连个博客都没发，只在定价页改了个版本号。但数据很能打：跟 Claude Fable 5 对比，9 项 Agent 基准测试平均只差 5.3%，其中两项还反超。关键是价格，Fable 5 输入 $10/百万 token，V4 Pro 只要 $0.435😃"

实用点

对成本敏感的 agent 开发者是重大利好。若你的工作负载以 Agent 基准测试为主（如工具调用、多步推理），V4 Pro 能以极低成本达到接近顶级模型的性能。建议立即在 API 端测试 0813 版本，对比现有 Claude 账单，评估迁移可行性。注意：官方未发博客，仅定价页更新，需自行验证稳定性。

"Grok 4.6 reaches #1 on @databricks" / "SPACEXAI: Grok 4.6 leads on the two strongest knowledge-work / real-world productivity benchmarks (GDPVal-AA and AA-Briefcase) and on the legal benchmark, while remaining highly competitive on coding-agent and general intelligence metrics."

"The ChatGPT desktop app is now available in preview for desktop variants of these Linux distributions: Ubuntu 24.04 LTS and 26.04 LTS, Debian 13, Fedora 43 and 44. Install with .deb or .rpm packages for x64 or ARM64."

05 工具更新

LogTape：零依赖日志库，支持 Deno/Node/Bun/浏览器与边缘函数

"LogTape is a zero-dependency logging library that lets libraries log safely without configuration, while keeping full control in the hands of applications. Runs on Deno, Node.js, Bun, browsers, and edge functions. Built-in data redaction via pattern or field-based approaches."

实用点

对构建跨运行时库的开发者很有价值。零依赖设计避免依赖冲突，内置数据脱敏（pattern/field 两种方式）适合处理敏感日志。支持 Express、Fastify、Hono、Koa、Drizzle ORM 的一等集成，可无缝替换现有日志方案。层级化分类支持细粒度日志级别控制。
