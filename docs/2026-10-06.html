02 工具更新

Hermes Agent 官网收录 326 个真实用法，含 /rollback 检查点回滚

"开源 AI 助手 Hermes Agent 的官网，收录了真实用户的 326 个用法……有个用户的 Hermes 一口气删光了源码，还顺手 git reset --hard，结果他敲了句 /rollback 1 就全救回来了！" 原文摘录（补充）："想用 /rollback 的话，得先用 hermes chat --checkpoints 打开检查点，现在的版本还要敲 /rollback 1 --all，才会连你自己的文件一起恢复"

实用点

两个可迁移的设计点——(1) 死规则任务（如"每 5 分钟查内存超 85% 告警"）让 agent 生成脚本定时跑，之后不再调模型，token 成本归零；(2) agent 的文件操作必须配检查点，否则一次 git reset --hard 就是灾难。注意 /rollback 默认不恢复你自己的文件，需加 --all。

03 工具更新

Claude Cowork 任务默认上云：本地文件夹按需上传，合盖也能继续跑

"能读写你电脑文件的 Claude Cowork，10 月 6 日起 Pro 和 Max 会员新建的任务一律上云！……文件夹还在你电脑上，用到哪个文件才拷一份上去；关掉桌面端任务照样跑，只是读不到本地文件；已经开始的本地任务能接着做完。" 原文摘录（补充）："不过 Cowork 里的项目和定时任务，没法带到 Claude Code 里。"

实用点

这是权限边界的变化——任务不再受本机 VM 生命周期约束，但"读不到本地文件"意味着依赖本地路径的定时任务会静默失败。想在本地跑，官方推荐换桌面版 Claude Code，但 Cowork 的项目与定时任务不可迁移，迁移前先盘点哪些任务依赖本地文件。

04 行业趋势

Google 暂停开源漏洞赏金收代码漏洞，称被 AI 垃圾报告刷停

"Google 官宣：开源漏洞赏金暂停收代码漏洞了！被 AI 垃圾报告刷停了……开源项目 curl 早就经历过这事，去年被刷爆，今年干脆把赏金全撤了。撤了之后，到 4 月 AI 垃圾报告只占 6% 左右，去年还有 28%。意外的是，报告量反而是去年的两倍，几乎都用了 AI，真漏洞的比例却从 5% 左右涨到了 16%！"

实用点

对做安全 agent 或漏洞扫描工具的人是重要反例——"AI 提高报告量"不等于"提高有效信号"，赏金机制本身会被生成成本下降击穿。curl 的数据说明：撤掉金钱激励后，AI 辅助报告的真漏洞占比反而上升，值得在设计 agent 输出评审流程时参考。

05 大佬官方

OpenAI 开始给 ChatGPT / Codex 文本加水印，先覆盖欧盟

"In the EU, we'll start watermarking eligible text from ChatGPT and Codex over the coming weeks to comply with the EU AI Act. Customers using our API can turn on text watermarking for select models worldwide today." 原文摘录（补充）："Watermarks have limits. They're often undetectable, especially in short passages. Rewriting or translating text can completely remove the watermark. That's why, for now, only approved researchers will have access to our detector."

实用点

OpenAI 自己承认水印在短文本中常检测不到、改写或翻译即可完全移除——所以不要把它当作可靠的溯源手段。对 API 用户：水印是可选项，且官方称不影响能力、速度与可读性；对面向欧盟的产品，需评估合规时间表。

06 工具更新

vibe-wise：Claude Code 插件，写码前先逼你想方案，按水平分三档

"插件叫 vibe-wise，用了它之后，你让 AI 做个功能，它会先问你打算怎么设计，你点头了它才动手写，写完还会讲清楚改了哪些代码、跑了哪些测试。并且按水平分初级、中级、高级三档，选初级会多解释、多画图。" 原文摘录（补充）："不过用 Codex、Cursor 的朋友还得等等，社区移植的 PR 还没合并。"

实用点

这是"反向 harness"思路——不是让 agent 更自主，而是强制在动手前插入人类设计确认，适合带新人或自己学新栈时用。目前仅 Claude Code 可用，Codex / Cursor 移植未合并。

07 工具更新

HeyGen 开源 HyperFrames 出免费桌面 App：在画面上圈出问题让 AI 改

"HeyGen 开源的视频框架 HyperFrames 刚出了免费桌面 App，一句话就能让你的 Claude Code 或 Codex 做出第一版。想改哪个词，选中留条评论就行，攒几条再一起发给 AI 改。" 原文摘录（补充）："Windows 版还没出，可以先给 Claude Code 或 Codex 装上官方 Skill 凑合用，只是没法圈画面改：npx skills add heygen-com/hyperframes"

实用点

把"视觉反馈"变成结构化输入（选中 + 评论 + 批量提交）是 AI 生成视频工作流里少见的实用交互。Mac 用户可直接试桌面版；Windows 用户只能先用 Skill，且失去圈选改稿能力。

Agent Deck：一个终端面板同时看所有在跑的 AI 编码会话
